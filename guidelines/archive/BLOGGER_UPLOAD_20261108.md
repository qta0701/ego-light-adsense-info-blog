3. `await taskSpace(spaceName,{profileId:target.id})`로 한 Space를 생성하고 반환한 `spaceId`로 재개한다. `task.page('p1').goto(제공된 Blogger URL)`로 접속한다.

- **bootstrap 연결 실패**: 기존 Space 재개 명령이 기본 샌드박스에서 `Failed to connect to ego_cli bootstrap`으로 끝났다. 실행 환경의 권한 절차를 거쳐 동일 스크립트를 샌드박스 밖에서 실행하자 연결됐다. 같은 제한 환경에서 반복 호출하거나 새 Space·다른 브라우저로 우회하지 않는다. 이번 명령은 검색만 수행했으며, 생성·업로드·발행 명령의 불명확한 실패에는 그대로 재실행하기 전에 실제 상태를 확인한다.

- **D 완료와 파일 누락 불일치**: 키워드 폴더 전체와 프로젝트의 HTML/TXT 파일을 검색했지만 해당 쌍은 없었다. 조사 Markdown과 이미지만 있었다. D=`ㅇ`를 근거로 본문을 추정하거나 빈 글을 생성하지 않는다. 다른 저장 경로 또는 명시적인 재작성 의사를 확인한 뒤 같은 대상의 작업을 재개한다.

### 8.2 실패한 시도·한계: 그대로 반복하지 않을 것

- **파일 선택창 이벤트 시간초과**: `waitForFileChooser()` + `찾아보기` 클릭이 실패했다. 같은 네이티브 창 시도를 반복하지 말고, 업로드 UI 준비를 확인한 뒤 이미 존재하는 `input[type=file]`에 `setInputFiles`를 사용한다.
- **메뉴 전환 직후 입력 탐색 실패**: 메뉴가 열리기 전에 다음 조작을 보내면 파일 입력이 없었다. 중간 UI 상태가 달라지는 지점에는 selector 대기를 둔다.
- **HTML textarea가 빈 값**: `textarea.Fdco1c`는 실제 CodeMirror 상태와 다를 수 있다. 라이브 원고 비교에 사용하지 않는다. 저장된 본문 비교는 CRLF/LF 차이만 허용하며 모든 공백을 지우지 않는다.
- **오래된 snapshot·중복 DOM**: 이동 직후 URL만 바뀌고 이전 편집기 요소가 남아 있었다. 일반 `document.querySelector`가 숨겨진 이전 필드를 반환할 수 있다. 현재 활성 패널의 snapshot ref/semantic locator와 실제 가시성을 사용한다. 영역을 무조건 다시 클릭해 닫지 않는다.
- **라벨 fill만으로 미저장**: 입력 문자열이 보여도 모델에 반영되지 않아 라벨이 빠졌다. 8.1의 키보드 확정 방식으로 같은 공개 글에 라벨만 보완했다. 업데이트 후 원래 URL·datePublished 유지 확인. 신규 글 생성이나 초안 되돌리기를 하지 않았다.
- **맞춤 퍼머링크 미반영(미해결)**: `맞춤 퍼머링크`의 text/정확 role 선택은 실패했고 현재 radio ref 선택 후 `맞춤 퍼머링크 입력`에 fill한 값과 미리보기 주소는 확인됐지만, 실제 발행은 `blog-post.html`이었다. **fill 결과·미리보기 주소만으로 성공 처리하지 않는다.** 다음 실행은 발행 전에 저장 후 편집기에 재진입하여 맞춤 radio와 저장값을 재검증한다. 키보드 입력 확정은 라벨에서만 검증됐으므로 퍼머링크 성공 절차로 단정하지 않는다. 이번 공개 주소는 유지했다.
- **미리보기 재사용·내용 잔류**: 기존 미리보기 탭이 있으면 새 popup 이벤트가 발생하지 않을 수 있다. 래퍼 새로고침 후에도 이전 HTML이 남았던 경우, 저장 본문을 재진입으로 확인한 뒤 **Agent가 만든 미리보기 탭만** 닫고 같은 Space에서 다시 열자 최신 링크 5개가 확인됐다. 글·Space를 새로 만들지 않는다.
- **기본 reload 시간초과**: 로딩 완료 대기만 실패했어도 문서는 열려 있었다. 현재 상태를 확인한 뒤 동일 편집 URL을 `goto(...,{waitUntil:'domcontentloaded',timeout:30000})`로 재진입했다. 생성·업로드 스크립트를 재실행하지 않는다.
- **미리보기 가젯 오류**: LinkList1 렌더 오류는 공개 페이지에서 재현되지 않았다. 미리보기 오류만으로 본문이나 테마를 변경하지 않는다.
- **테마의 중복 description(범위 밖)**: 공개 head에는 사이트 공통 설명과 요청한 글 설명이 함께 존재했다. 글 검색 설명은 정상 반영됐지만 공통 테마 SEO 중복은 별도 개선 대상이다. 메타데이터 검사는 첫 meta 한 개만 읽지 말고 해당 속성 전체를 제한적으로 읽는다.
- **이미지 URL의 런타임 변환**: 공개 테마가 src의 `/s1600/`을 `/s1600-rw/`로 바꿨다. 원본 확대 href는 업로드 URL 그대로였다. 문자열이 다르다는 이유만으로 재업로드하지 말고 파일명·동일 리소스 경로·크기·로딩을 대조한다.
