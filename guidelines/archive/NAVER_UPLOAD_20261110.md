## 기록·검증 범위

- 실제 예약 제출, 여러 계정 동시 발행, 신규 로그인/2FA는 이번 1건에서 수행하지 않았다. 예약시각의 KST 변환·자정 넘김·균등 배정은 로컬 검사로 확인했다. 운영 가이드의 해당 부분은 다음 실행에서 UI 성공을 확인해야 한다.
- 첫 실행에서는 본문 입력 전 공통 claim helper를 적용하지 못했다. 실행은 단일 채팅·단일 계정이었다. 다음 실행 절차에 기존 로컬 claim과 clipboard lease를 명시했으며, 이번에 claim 확보/해제를 했다고 기록하지 않는다.
- 공개 완료 시각은 서버 내부 시각이 아닌 성공 화면 관찰 시각이다. 동일 결과를 재개할 때 현재 시각으로 바꾸지 않는다.
- 원고 내용은 사용자 제공 원고를 사용했다. 전체 사실 재조사·새 이미지 생성·광고 수익 점검은 이 업로드 작업에 포함하지 않았다.
- 공개 페이지 검증 파일: 키워드 `웹조사/evidence/naver-public-checks.json`.
- 재개/중복 방지 상태: 키워드 `웹조사/evidence/naver-state.json`.
- 변환 HTML/조각/상세 라운드/캡처: `.session/naver-upload-20261110/` (로컬 실행 자료, 일반 다음 요청에서 통째로 읽지 않음).
- 재사용 도구: `tools/naver_workflow.py`, `tools/naver_editor.mjs`; 검사: `tools/test_naver_workflow.py` 5개 통과.
