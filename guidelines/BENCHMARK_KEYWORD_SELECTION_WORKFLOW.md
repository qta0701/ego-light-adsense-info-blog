## 2. ego-browser 유동적 Space 분할 및 시트 탐색 표준

1. **사전 준비**:
   - 작업을 시작하기 전 `.antigravity/rules.md`, `guidelines/CHROME_AGENTS_USAGE_GUIDE.md`, `guidelines/크롬에이전트_활용법.md`, `guidelines/AGENT_DESKTOP_GUIDE.md`를 확인한다.
   - `ego-browser skill`을 끝 표시(`[ego-browser:skill] end of guide`)까지 읽고 공개 SDK를 사용한다.
2. **탐색 대상 범위에 따른 Space 유동적 배분**:
   - **특정 소수 카테고리 지정 시 (1~7개 내외)**:
     - 2~3개의 Space(`kw-space-1`, `kw-space-2`, `kw-space-3`)로 카테고리 헤더열을 분배한다.
   - **"모든 카테고리 키워드 헤더열" 등 광범위한 요청 시 (10개 이상~수십 개)**:
     - 1행을 스캔하여 대상 탭의 모든 유효 키워드 헤더열(공란, 날짜, 검색량 열 제외)을 자동 식별한다.
     - 시스템 리소스와 브라우저 안정성을 고려하여 **3~5개 Space(권장 3~5개, 최대 5개)**로 유동적으로 TaskSpace를 생성한다.
     - 전체 카테고리 열을 유사한 주제군(블록 단위) 또는 열 순서대로 각 Space에 균등 분할 배정한다.
       - *예시 (5개 Space 배분 시)*:
         - `Space 1`: 금융/은행/카드 계열 열들
         - `Space 2`: 통신/핸드폰/가전/다운로드 계열 열들
         - `Space 3`: 앱사용/카카오톡/코레일/중고거래 계열 열들
         - `Space 4`: 보험/증권/일반브랜드 계열 열들
         - `Space 5`: 서류/상품권/주차장/부동산/기타 열들
3. **셀 배경색(`#fce5cd`) 및 전체 열 데이터 정밀 추출**:
   - Google Sheets 웹 화면은 Canvas 기반으로 렌더링되므로 DOM 스냅샷만으로 수백 행의 텍스트와 정확한 Hex 배경색(`#fce5cd`)을 판별하기 어렵다.
   - 열린 `ego-browser` Space에서 대상 탭을 클릭하여 활성화하고 URL의 `gid`를 확인한 뒤, `page.fetch()`로 `export?format=xlsx&gid={gid}` 파일을 로컬 임시 경로에 다운로드하거나 `gsheets` CLI(`readonly inspect-cell`, `readonly read`)와 결합하여 **1행 전체 헤더 매핑**과 **각 카테고리 열의 `#fce5cd` 배경색 지정 행**을 100% 정확하게 식별한다.
   - 각 Space에서는 Google Sheets 이름 상자(`#t-name-box`)를 통해 배정된 카테고리 열과 후보 행 구간(예: `BZ33:BZ38`, `CC51:CC62` 등)으로 실제 포커스를 이동하여 탐색·검증을 수행한다.
4. **TaskSpace 정상 종료**:
   - 모든 Space의 탐색·검증이 끝나면 각 Space에서 `await task.finish({ keep: [] })`를 정확히 한 번 호출하여 불필요한 탭이나 Space를 남기지 않는다.

## 3. `#fce5cd` 배경색 기준점 판별 및 키워드 선별 기준

### 3.1 시작 행(`lastColoredRow + 1`) 판별 규칙
- 각 카테고리 키워드 열에서 배경색이 **`#fce5cd`** (XLSX ARGB: `FFFCE5CD`, Sheets API RGB: `red: 0.9882353, green: 0.8980392, blue: 0.8039216`)로 칠해진 **가장 마지막(가장 큰 행 번호) 행**을 찾는다.
- 선별 후보 탐색은 반드시 **`마지막 #fce5cd 행 번호 + 1`행부터** 아래 방향으로 순차 진행한다.
- 만약 해당 카테고리 열에 `#fce5cd` 배경색이 칠해진 셀이 하나도 없다면, 헤더 바로 아래인 **2행부터** 순차 탐색한다.

### 3.2 콘텐츠 적합 키워드 선별 기준 (How-to / 순차 가이드형)
단순히 검색량이 높다고 무조건 위에서 N개를 가져오지 않으며, **블로그 글로 작성했을 때 단계별 과정·방법을 안내할 수 있는 키워드**인지 반드시 판별한다.

> [!IMPORTANT]
> **과정(Process) 안내 적합성 중심 판별 원칙**:
> 키워드 끝에 `~ 방법`, `~ 하는법` 같은 단어가 직접 붙어있지 않더라도(명사형 키워드라도), **사용자가 검색을 통해 해당 사이트·앱을 찾아가서 메뉴 진입 → 조회·신청·확인·환불·해지·발권 등의 실제 일련의 과정을 밟아야 하는 목적성 키워드**는 모두 훌륭한 순차 가이드형(How-to / Step-by-step) 콘텐츠 대상이다.
> - 예: `티머니 환불`, `배민클럽 환불` → 앱/사이트에서 환불 메뉴를 찾아가 계좌 입력 및 신청하는 상세 과정 안내 가능
> - 예: `코레일 시간표` → 레츠코레일 또는 코레일톡에서 KTX/일반열차 노선별 운행 시간표를 검색·조회하고 확인(또는 엑셀 다운로드)하는 과정 안내 가능

| 구분 | 판별 기준 | 구체적 예시 |

## 4. 구글시트 업데이트 및 `#fce5cd` 마킹 절차

1. **타겟 시트(`1.애드센스 키워드표`) 사전 확인 및 탭별 업데이트**:
   - 선별된 키워드들을 대상 탭별로 그룹화한다(단일 탭 지정 시 해당 탭으로 일괄 배정, 다중 탭 배정 시 상기 매핑표에 따라 배정).
   - 업데이트 대상인 각 탭의 `I열(메인 키워드)`을 읽어 기존 키워드 목록(중복 방지)과 **마지막으로 값이 채워진 행 번호(`lastRow`)**를 확인한다.
   - 각 탭마다 `lastRow + 1`행부터 빈 행임을 재확인한 뒤, 배정된 키워드들을 `'탭이름'!I{lastRow+1}:I{lastRow+K}` 범위에 정확히 기록한다 (`gsheets mutate batch` 또는 `write`).
   - 다른 열(`A~H`, `J~M`)이나 기존 데이터 행의 값·수식·서식은 절대 건드리지 않는다.
2. **소스 시트(`벤치마크 블로그 키워드 추출`) `#fce5cd` 배경색 지정**:
   - 이번에 선별하여 타겟 시트에 업데이트한 모든 키워드 셀(예: `BZ35`, `CC58`, `CI17` 등)에 `#fce5cd` 배경색을 지정하여 사용 완료 표시를 남긴다.
   - **서식 보존 원칙**: 기존 글꼴(`Arial`, `11pt` 등)이나 정렬이 초기화되지 않도록 `gsheets mutate raw-batch`의 `repeatCell` 요청에서 `fields: "userEnteredFormat.backgroundColor"`만 지정하여 배경색(`red: 0.9882353, green: 0.8980392, blue: 0.8039216`)만 정밀하게 변경한다.
3. **사후 검증 및 완료 보고**:
   - 업데이트 직후 타겟 시트의 추가된 각 탭 `I열` 행들과 소스 시트의 `#fce5cd` 마킹 셀을 재조회(`readonly read`, `readonly inspect-cell`)하여 값이 정확히 들어갔는지 확인한다.
   - 사용자에게 Space별 분배 내역, 카테고리별 마지막 `#fce5cd` 기준 행, 선별된 키워드(셀 좌표·검색량·선별 사유), 제외된 대표 단답형 키워드 사유, 그리고 타겟 시트 탭별 업데이트 행 번호(`I열`)를 표 형태로 깔끔하게 보고한다.
   - 작업 완료 시 `tools/show-notification.ps1`을 통해 무음 Windows 알림을 실행한다.
