무이자 표시와 금액은 카드사와 행사에 따라 바뀌므로 결제 직전에 확인하는 것이 좋아요.

구매할 상품의 상세 화면이나 번개톡에서 **구매하기**를 선택하고 거래 방식을 확인하세요. 택배거래라면 배송지도 한 번 더 살펴봅니다.

| 🪜 단계 | ✅ 확인할 일 |
| :---: | :---: |
| 1️⃣ 결제수단 | 일반결제의 신용·체크카드 선택 |
| 2️⃣ 카드 선택 | 사용할 카드사 확인 |
| 3️⃣ 결제 조건 | 일시불 또는 표시된 할부 조건 확인 |
| 4️⃣ 인증 | 금액을 확인하고 카드사 안내에 따라 인증 |

공식 활용백서의 화면은 예시이므로 현재 앱의 메뉴 위치가 다를 수 있어요. 특히 무이자라고 표시된 개월 수와 적용 조건을 결제 화면에서 확인한 뒤 진행하세요.

번개장터 고객센터는 결제 화면에서 간편결제 등록을 시작하거나 앱 **MY → 간편결제 관리 → 카드 추가**에서 미리 등록할 수 있다고 안내합니다.

| 🔐 순서 | 📌 확인할 내용 |
| :---: | :---: |
| 카드 추가 | 간편결제 관리 또는 결제 화면에서 시작 |
| 약관·본인인증 | 화면에 표시되는 절차 확인 |
| 등록 확인 | 카드 목록에 원하는 카드가 표시되는지 확인 |
| 결제 | 등록 카드를 선택하고 금액·조건 재확인 |

카드번호와 인증 정보는 결제 서비스의 공식 화면에서만 입력하세요. 상대방이 채팅이나 외부 링크로 인증 정보를 요구하면 거래를 멈추고 확인하는 것이 안전합니다.

## 4. 수수료와 법인카드 확인

번개장터 고객센터는 구매자가 부담하는 안전결제 수수료가 없다고 안내합니다. 다만 상품 가격과 배송비 등 실제 결제 화면에 표시된 총액은 별도로 확인하세요.

| 🔍 항목 | 💡 확인할 점 |
| :---: | :---: |
| 구매자 안전결제 수수료 | 고객센터 안내 기준 없음 |
| 할부 | 카드사·금액·시점별 표시 조건 확인 |
| 법인카드 | 회사의 결제 가능 업종과 카드사 인증 확인 |
| 결제 실패 | 카드사 또는 회사에 이용 가능 여부 문의 |

법인카드는 회사가 카드사에 설정한 업종 제한에 따라 사용이 막힐 수 있어요. 안내된 인증 방법으로 진행되지 않는다면 반복 결제 전에 카드사와 회사에 확인하세요.
