# 넷플릭스 해지방법｜PC·휴대폰에서 멤버십 종료하기

넷플릭스 멤버십은 계정의 멤버십 관리 페이지에서 해지를 선택하고 완료해야 종료돼요. 앱 삭제만으로는 해지되지 않습니다.

먼저 실제 청구처를 확인하고, 해지 후에는 확인 이메일과 이용 종료일을 살펴보세요.

결제처에 따라 취소 위치가 달라지니 설정을 찾기 전에 청구 내역부터 확인하면 좋아요.

| 📺 넷플릭스 해지와 결제처 확인하기 👇 |
| :---: |

https://app.supportimes.com/2026/11/pc.html

## 1. 해지 전에 확인할 것

[이미지 배치 지시: `google-official-marked.png` - Google 검색에서 실제로 연 공식 결과 · 넷플릭스 해지 방법 삽입. 캡션: "Google 검색에서 실제로 연 공식 결과 · 넷플릭스 해지 방법"]

2026년 11월 13일 확인한 넷플릭스 고객센터 안내 기준입니다. 계정에서 로그아웃하거나 휴대폰의 앱을 지우는 것만으로는 멤버십이 종료되지 않아요.

| 🔍 확인 항목 | ✅ 살펴볼 내용 |
| :---: | :---: |
| 로그인 계정 | 실제로 멤버십을 이용하는 계정인지 |
| 청구처 | 넷플릭스 직접 결제인지 제휴사를 통한 결제인지 |
| 결제 주기 | 계정에 표시된 다음 결제일과 이용 종료일 |

가족과 계정을 함께 사용한다면 해지 사실도 공유해 두세요. 다른 사용자가 다시 멤버십을 시작하면 결제가 재개될 수 있어요.

해지 버튼을 누른 뒤에도 완료 화면과 이메일을 확인해야 상태를 놓치지 않을 수 있습니다.

## 2. 멤버십 관리에서 해지 완료하기

[이미지 배치 지시: `01_official_cancel_step1.webp` - 멤버십 관리에서 해지 항목 펼치기 삽입. 캡션: "멤버십 관리에서 해지 항목 펼치기"]

[이미지 배치 지시: `02_official_cancel_step2.webp` - 해지 완료하기 버튼 확인 삽입. 캡션: "해지 완료하기 버튼 확인"]

PC나 휴대폰 브라우저에서 넷플릭스에 로그인하고 계정의 **멤버십 관리** 페이지를 엽니다. 공식 안내는 **해지 → 해지 완료** 순서로 진행하도록 설명해요.

| 🪜 순서 | 📱 확인할 일 |
| :---: | :---: |
| 1️⃣ 로그인 | 해지할 멤버십의 계정으로 로그인 |
| 2️⃣ 관리 | 계정에서 멤버십 관리 열기 |
| 3️⃣ 해지 | 해지를 선택하고 해지 완료 누르기 |
| 4️⃣ 확인 | 등록 이메일의 확인 메일과 종료일 확인 |

중간 화면만 보고 닫지 말고 최종 확인까지 진행하세요. 이메일이 보이지 않으면 스팸함과 등록된 이메일 주소도 확인해 보세요.

## 3. 해지 버튼이 보이지 않을 때

넷플릭스가 포함된 통신사 요금제나 제휴 상품 등으로 청구된다면 해당 결제 파트너를 통해 해지해야 할 수 있어요. 계정의 멤버십 정보와 실제 결제 내역에서 청구처를 확인하세요.

| 💳 청구 방식 | 🧭 확인할 곳 |
| :---: | :---: |
| 넷플릭스 직접 청구 | 넷플릭스 계정의 멤버십 관리 |
| 앱스토어 구독 | 해당 계정의 구독 관리 화면 |
| 통신사·패키지 | 해당 사업자의 상품·구독 관리 안내 |

앱스토어 구독 목록에 항목이 없다면 다른 계정으로 결제했는지와 카드 명세서의 청구처를 살펴보세요. 실제 제공 여부와 취소 경로는 가입 상품에 따라 달라질 수 있습니다.

[이미지 배치 지시: `04_official_pause_step2.webp` - 한 달 일시정지 옵션 확인 삽입. 캡션: "한 달 일시정지 옵션 확인"]

결제 주기가 남은 상태에서 해지하면 일반적으로 현재 결제 주기가 끝날 때까지 시청할 수 있어요. 계정 보류나 기프트카드·프로모션 잔액 등은 적용 시점이 다를 수 있으니 완료 화면의 날짜를 확인하세요.

| 🗓️ 선택 | 💡 확인할 점 |
| :---: | :---: |
| 해지 | 확인 이메일과 표시된 종료일 확인 |
| 일시정지 | 대상 계정에 옵션이 보이는지 확인 |
| 재가입 | 재시작 시 표시되는 요금과 결제일 확인 |
| 계정 공유 | 다른 기기의 재시작 가능 여부 확인 |

일시정지는 모든 계정에서 제공되는 기능이 아니에요. 잠시 쉬고 싶다면 멤버십 관리 화면에 옵션이 나타나는지와 적용 조건을 먼저 살펴보세요.
