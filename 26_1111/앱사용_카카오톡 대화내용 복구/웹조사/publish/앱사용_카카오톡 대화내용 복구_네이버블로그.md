## 2. 무료 대화 임시 백업과 복원 순서

[이미지 배치 지시: `01_official-print.png` - 카카오톡의 무료 임시 백업 방법 삽입. 캡션: "카카오톡의 무료 임시 백업 방법"]

[이미지 배치 지시: `02_official-print.png` - 무료 백업에서 복원하는 방법과 14일 복원 기한 삽입. 캡션: "무료 백업에서 복원하는 방법과 14일 복원 기한"]

기존 휴대폰에서 카카오톡 **더보기 → 설정 → 백업 → 대화 임시 백업**을 선택하고 비밀번호를 설정해요. 백업이 끝날 때까지 앱을 종료하거나 다른 앱으로 이동하지 마세요.

| 🪜 순서 | 📌 할 일 |
| :---: | :---: |
| 1️⃣ 백업 | 기존 기기에서 임시 백업과 비밀번호 설정 |
| 2️⃣ 로그인 | 새 기기에서 기존 계정으로 로그인하고 번호 인증 |
| 3️⃣ 복원 | 프로필 입력 후 복원 화면에서 백업 일시 확인 |
| 4️⃣ 완료 | 복원하기 선택 → 백업 비밀번호 입력 → 완료 대기 |

복원 화면에서 백업 일시와 운영체제를 확인한 뒤 진행하세요. 완료되면 **카카오톡 시작하기**를 눌러 대화를 확인하면 됩니다.

## 3. 무료 백업에서 빠지는 자료

무료 임시 백업은 텍스트 대화 중심이에요. 사진이나 동영상까지 모두 돌아올 것으로 생각하고 기존 기기를 초기화하면 필요한 자료를 잃을 수 있습니다.

| 📦 자료 | 📝 무료 백업 범위 |
| :---: | :---: |
| 일반 텍스트 대화 | 백업 대상 |
| 사진·동영상·첨부파일 | 제외 |
| 4,000자 이상 메시지 | 제외 |
| 비밀채팅·오픈채팅 | 제외 |

백업 기한은 14일입니다. 새 기기에서 복원하기 전까지 백업이 완료된 이전 기기를 보관할 수 있다면 자료 확인에 도움이 돼요.

## 4. 사진도 필요하다면 톡클라우드 확인

[이미지 배치 지시: `03_official-print.png` - 톡클라우드 백업·복원과 이전 데이터 백업 확인 삽입. 캡션: "톡클라우드 백업·복원과 이전 데이터 백업 확인"]

톡클라우드는 구독 후 대화와 미디어를 백업하는 방법입니다. 카카오톡 **더보기 → 톡클라우드 → 시작하기**에서 My 비밀번호를 입력하고, 과거 데이터 백업에서 필요한 연락처와 미디어를 선택하세요.

| ☁️ 확인 항목 | 💡 확인 이유 |
| :---: | :---: |
| 구독 및 My 비밀번호 | 서비스 이용과 복원에 필요 |
| 과거 데이터 백업 | 시작 전 자료가 자동으로 모두 담기는 것은 아님 |
| 백업 완료 여부 | 기기 삭제 전에 필요한 자료가 저장됐는지 확인 |

로그인 과정에서 톡클라우드 복원을 건너뛰었다면 **더보기 → 톡클라우드 → 메뉴 → 설정 → 대화내용 복원**에서 다시 시도할 수 있다고 카카오는 안내합니다. 구독 조건과 화면은 이용 시점에 다시 확인하세요.
