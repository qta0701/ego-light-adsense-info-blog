## 1. GS25와 CU 요금·규격 비교

2026년 11월 13일 확인한 번개장터 고객센터의 상세 운임표 기준입니다. 실제 결제액과 할인 적용 여부는 예약·접수 화면에서 다시 확인하세요.

| ⚖️ 포장 후 무게 | 🟢 GS25 | 🟣 CU |
| :---: | :---: | :---: |
| 500g 이하 | 1,900원 | 1,800원 |
| 1kg 이하 | 2,300원 | 2,100원 |
| 5kg 이하 | 2,700원 | 2,500원 |

두 서비스 모두 5kg 초과는 접수할 수 없어요. GS25는 박스 세 변의 합이 80cm를, CU는 100cm를 넘으면 접수할 수 없습니다. GS25는 물품 가액 30만 원 초과~50만 원 이하에 500원 할증이 안내돼 있어요.

수령할 지점이 정해져 있다면 해당 브랜드의 택배기 설치 여부도 확인해 보세요.

| 📱 순서 | ✅ 확인할 내용 |
| :---: | :---: |
| 1️⃣ 배송 예약 | 거래 화면에서 배송 예약 시작 |

반값택배는 선불만 가능해요. GS25 반값택배는 BOX25 수령을 지원하지 않으며, Post Box가 설치된 점포를 이용해야 합니다.

## 3. 편의점에서 접수하기

[이미지 배치 지시: `05_official_postbox.jpg` - 일반 편의점택배 택배기에서 예약 접수하는 예시 삽입. 캡션: "일반 편의점택배 택배기에서 예약 접수하는 예시"]

물품을 안전하게 포장하고 예약한 브랜드의 택배기 설치 점포로 가져가세요. 택배기에서 예약 접수를 선택해 예약번호를 입력하고 안내에 따라 무게를 측정합니다.

| 🪜 단계 | 📦 할 일 |
| :---: | :---: |
| 포장 | 내용물이 움직이지 않게 보호하고 크기·무게 측정 |
| 예약 조회 | Post Box에서 예약번호 입력 |
| 운송장 | 출력된 운송장을 박스에 부착 |
| 접수 | 점포 안내에 따라 선불 결제하고 물품 맡기기 |

포장 후 무게가 예상과 다르면 요금 구간이 달라질 수 있어요. 접수 전에 택배기 화면의 무게와 금액을 확인하고 운송장 정보를 보관하세요.

## 4. QR코드로 수령하고 기한 확인

받는 점포에 도착하면 알림톡으로 전달된 QR코드를 점포 근무자에게 보여 주고 물품을 찾습니다. 도착 알림을 받으면 수령 일정을 바로 확인하세요.

| 🏪 브랜드 | ⏰ 도착 후 수령 기한 |
| :---: | :---: |
| GS25 반값택배 | 3일 이내 |
| CU 반값택배 | 4일 이내 |

기한 내 찾지 않으면 보낸 사람의 주소지로 반송된다고 번개장터는 안내합니다. 제주도는 제주도 내 접수·배송으로 안내하므로 예약 화면에서 출발지와 도착지 조합을 확인하세요.
