# 코레일 내일로 패스 가격과 좌석 지정 방법, KTX 횟수까지

코레일 내일로 패스는 나이 제한 없이 이용할 수 있는 철도 여행권이에요. 선택 3일권과 연속 7일권 중 일정을 골라 구매합니다.

패스만으로 바로 탑승하는 것은 아니에요. 열차별 이용권을 발권해야 하니 좌석 횟수도 함께 확인해 볼게요.

여행 일수와 나이에 맞는 권종을 먼저 비교하면 구매 후 일정을 다시 짜는 수고를 줄일 수 있어요.

가격이나 운영 조건은 바뀔 수 있으므로 결제 화면에서도 본인 권종과 금액을 다시 확인하세요.

## 2. KTX와 일반열차 좌석은 몇 번일까?

[이미지 배치 지시: `google-official-marked.png` - Google 검색에서 실제로 연 공식 결과 · 패스 소개 삽입. 캡션: "Google 검색에서 실제로 연 공식 결과 · 패스 소개"]

코레일은 패스 유효기간 중 KTX 좌석을 하루 1회, 총 2회 지정할 수 있다고 안내합니다. 일반열차는 좌석을 하루 2회 지정할 수 있어요.

| 🚄 이용 구분 | 🪑 지정 또는 이용 횟수 |
| :---: | :---: |
| KTX 좌석 | 하루 1회, 유효기간 중 총 2회 |
| 일반열차 좌석 | 하루 2회 |
| 일반열차 입석·자유석 | 횟수 제한 없음 |

일부 열차는 입석이나 자유석을 운영하지 않아요. 일반석에 빈자리가 보여도 패스용 좌석이 매진됐다면 지정할 수 없으니 원하는 시간대는 미리 조회하세요.

## 3. 구매 후 열차별 이용권 발권하기

[이미지 배치 지시: `02_official-print.png` - 패스 이용 방법과 구매 기간 삽입. 캡션: "패스 이용 방법과 구매 기간"]

패스는 이용시작일 기준 7일 전부터 구매할 수 있어요. 코레일+ 앱이나 홈페이지, 역 창구에서 구매하고 이용할 열차의 좌석지정권 또는 입석·자유석 이용권을 별도로 발권합니다.

| 🪜 순서 | ✅ 확인할 일 |
| :---: | :---: |
| 1️⃣ 패스 구매 | 권종과 이용시작일을 확인하고 결제 |
| 2️⃣ 열차 조회 | 출발지·도착지와 날짜를 선택 |
| 3️⃣ 이용권 발권 | 좌석 또는 입석·자유석 이용권 발권 완료 확인 |
| 4️⃣ 탑승 준비 | 신분증·패스·열차별 이용권 지참 |

패스만 보여 주고 탑승하면 안 돼요. 코레일은 필요한 증표를 갖추지 않은 경우 최대 30배의 부가운임이 부과될 수 있다고 안내합니다.

## 4. 일정 변경과 반환 전 체크

[이미지 배치 지시: `03_official-print.png` - 이용 전 확인할 내일로 패스 주의사항 삽입. 캡션: "이용 전 확인할 내일로 패스 주의사항"]

발권한 좌석지정권은 열차 출발 시각 전까지 반환하면 사용 횟수를 복구할 수 있어요. 출발 후에는 원칙적으로 반환할 수 없으므로 일정이 달라졌다면 출발 전에 처리하세요.

| ⏰ 반환 시점 | 💳 공식 안내의 조건 |
| :---: | :---: |
| 구매 후 30분 이내 | 수수료 없이 반환 가능 |
| 이용시작일 하루 전까지 | 최저수수료 400원 공제 |
| 시작일 이후 종료일 이전 | 이용권을 사용하지 않은 경우 5% 공제 후 반환 가능 |

좌석지정권이나 입석·자유석 이용권을 사용한 경우에는 패스 반환이 제한됩니다. 실제 반환 전 최신 규정과 예외를 결제처에서 확인하세요.
