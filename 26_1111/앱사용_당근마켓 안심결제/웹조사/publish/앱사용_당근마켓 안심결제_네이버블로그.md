# 당근마켓 안심결제 방법과 한도, 상태별 취소 절차

당근 안심결제는 구매자가 낸 물품대금을 당근페이가 보관했다가 구매확정 시 판매자에게 전달하는 서비스예요.

거래 채팅방에서 결제를 진행하고, 물품을 직접 확인한 뒤 구매확정을 눌러 주세요.

결제 전에 한도와 표시된 수수료를 확인하면 거래 중 금액 때문에 다시 협의하는 일을 줄일 수 있어요.

| 🪜 단계 | ✅ 확인할 내용 |
| :---: | :---: |
| 거래 협의 | 물품 가격과 직거래·택배 방식을 확인 |
| 결제 | 당근 앱 안에서 금액과 수수료 확인 |
| 물품 확인 | 수령 후 구성품과 상태 확인 |
| 구매확정 | 문제가 없을 때 확정해 판매자에게 대금 전달 |

물건을 받기 전에 판매자가 구매확정을 요청해도 먼저 누르지 마세요. 확인 즉시 대금이 전달되므로 물품을 받은 뒤 상태를 살펴보는 것이 중요합니다.

## 2. 채팅방에서 요청하고 결제하기

[이미지 배치 지시: `01_official-03-escrow-app.jpg` - 출시 당시 당근페이 안심결제 앱 화면 예시 삽입. 캡션: "출시 당시 당근페이 안심결제 앱 화면 예시"]

당근 앱의 거래 채팅방에서 **당근페이 → 안심결제**를 찾아 요청합니다. 앱 버전에 따라 버튼 위치가 달라질 수 있으니 실제 거래 화면의 안내를 확인하세요.

| 📱 순서 | 🔍 확인할 일 |
| :---: | :---: |
| 채팅방 열기 | 거래 상대와 물품·가격·배송 방식 확인 |
| 안심결제 선택 | 당근 앱 안의 당근페이 메뉴에서 진행 |
| 결제 | 당근머니 또는 카드와 최종 금액 확인 |
| 수령 후 | 물품에 문제가 없는지 살펴보고 구매확정 |

외부 메신저로 받은 결제 링크나 별도 계좌로 수수료를 보내 달라는 요청은 주의하세요. 당근 앱을 직접 열어 원래 거래 채팅방에서 진행하는 것이 좋습니다.

## 3. 수수료와 결제 한도

당근페이 공개 안내의 구매자 보호 수수료는 거래 금액의 3.3%입니다. 예를 들어 물품값 10만 원에 적용하면 3,300원이에요. 실제 결제 전에는 화면에 표시되는 수수료와 배송비를 다시 확인하세요.

| 💳 결제 수단 | 📏 고객센터 안내 한도 |
| :---: | :---: |
| 당근머니·계좌 연결 성인 | 1회 190만 원 |
| 당근머니·계좌 미연결 성인 | 1회 50만 원 |
| 당근머니·미성년자 | 1회·1일 50만 원, 월 300만 원 |
| 카드·구매자 | 1회 190만 원, 월 500만 원 |

카드 구매자 월 한도는 안심결제·바로구매·바로구매 e쿠폰을 합산해 계산해요. 한도와 이용 조건은 바뀔 수 있으므로 결제 화면에서도 확인하세요.

## 4. 취소와 물품 문제 대처

[이미지 배치 지시: `daangn-escrow-marked.png` - 당근 고객센터에서 구매확정과 결제대금 전달 방식 확인 삽입. 캡션: "당근 고객센터에서 구매확정과 결제대금 전달 방식 확인"]

구매자의 취소 방법은 판매자의 수락과 배송 진행 상태에 따라 달라집니다. 거래 채팅방의 상태를 먼저 확인하세요.

| 🚚 상태 | 🧭 구매자가 확인할 방법 |
| :---: | :---: |
| 판매자 수락 전 | 직접 취소 가능, 결제 자동 취소 |
| 수락 후 배송 전 | 자세히 보기 → 거래 취소 요청, 판매자 수락 대기 |
| 운송장 등록 후 배송 중 | 구매자 취소 요청은 불가, 판매자에게 문의 |
| 물품에 문제 발생 | 구매확정 전 거래 채팅방에서 분쟁조정 확인 |

판매자가 물품을 보내지 않고 연락이 되지 않으면 당근에 문의해 거래 상황 확인을 요청할 수 있어요. 바로구매 택배의 48시간 자동확정 기준을 모든 채팅 안심결제에 그대로 적용하지 말고 거래 화면의 기한을 확인하세요.
