# 스팀 환불 방법｜14일·2시간 기준과 신청 순서

스팀 게임 환불은 구매한 계정으로 Steam 고객지원에 로그인해 구매 내역에서 요청할 수 있어요.

일반적인 게임 기준은 구매 후 14일 이내이면서 플레이 시간이 2시간 미만인지 확인하는 것입니다.

같은 게임을 여러 번 샀다면 날짜와 금액을 먼저 대조하면 다른 거래를 선택하는 실수를 줄일 수 있어요.

## 1. 신청 전 구매일과 플레이 시간 확인

2026년 11월 13일 확인한 Steam 고객지원 안내에 따르면 일반적인 게임 환불 기준은 구매일로부터 14일 이내와 플레이 시간 2시간 미만입니다.

| 🔍 확인 항목 | ✅ 살펴볼 내용 |
| :---: | :---: |

기준을 충족하지 못해도 요청을 제출할 수 있으며 Valve가 검토한다고 안내합니다. 다만 제출이 승인 보장은 아니므로 사정을 정확히 적어 주세요.

조건을 확인했다면 고객지원의 구매 메뉴에서 해당 거래를 찾아 요청을 시작해 보세요.

Steam 고객지원에 로그인하거나 Steam 클라이언트의 **도움말 → Steam 고객지원**을 엽니다. 로그인 후 **구매**를 누르고 환불하려는 구매 항목을 선택하세요.

| 🪜 순서 | 🖥️ 할 일 |
| :---: | :---: |
| 1️⃣ 구매 선택 | 고객지원의 구매 목록에서 거래 찾기 |
| 2️⃣ 문제 선택 | 실제 상황에 맞는 문제 유형 선택 |
| 3️⃣ 환불 요청 | 환불을 요청하고 싶습니다 선택 |
| 4️⃣ 제출 | 양식에서 환불 수단과 사유 확인 후 제출 |

목록에서 구매를 찾지 못하면 공식 도움말은 환불 요청 기간이 지났을 수 있다고 안내합니다. 로그인한 계정과 구매 내역을 먼저 다시 확인하세요.

## 3. 환불 수단과 처리 상태 확인

[이미지 배치 지시: `06_guide.png` - 환불 수단과 사유를 확인하는 요청 양식 삽입. 캡션: "환불 수단과 사유를 확인하는 요청 양식"]

요청 양식에 표시되는 **Steam 지갑** 또는 구매에 사용한 결제 수단 중 가능한 항목을 선택합니다. 결제 방식에 따라 원래 수단으로 환불할 수 없으면 Steam 지갑으로 환불될 수 있어요.

| ✉️ 단계 | ✅ 확인할 내용 |
| :---: | :---: |
| 요청 제출 | 계정 이메일의 접수 확인 메일 |
| 검토 결과 | 별도로 도착하는 처리 결과 메일 |
| 승인 후 | Steam 지갑 또는 원래 결제 내역의 반영 상태 |
| 지연 시 | 결제 수단의 처리 상황과 고객지원 안내 확인 |

접수 메일은 환불이 이미 완료됐다는 뜻은 아니에요. Steam 정책은 요청이 확인된 뒤 1주일 안으로 환불받는다고 설명하며, 결제수단별 반영은 다를 수 있습니다.

## 4. DLC·선물·예약 구매는 조건이 다를까?

기본 게임 외 구매는 별도의 조건이 적용될 수 있으므로 신청할 항목의 상세 안내를 확인하세요.

| 📦 구매 유형 | ⚠️ 확인할 점 |
| :---: | :---: |
| DLC | 구매 후 14일, 이후 기본 게임 플레이와 사용·변경 여부 |
| 선물 | 수락 여부와 수령인의 요청 여부 |
| 예약 구매 | 출시 시점과 출시 전 플레이 시간의 적용 기준 |
| 외부 구매 코드 | Steam 밖에서 산 코드인지 확인 |

Steam은 일부 DLC나 외부에서 구매한 코드에 환불 제한이 있다고 안내합니다. 상품별 예외를 구매 내역과 공식 정책에서 확인해 보세요.

## 5. 자주 묻는 질문

| **Q1. 14일이나 2시간 기준을 넘기면 신청할 수 없나요?** |
| :--- |
| A1. Steam은 기준에 해당하지 않아도 요청을 제출하면 환불 가능 여부를 검토한다고 안내합니다. |

| **Q2. 환불 접수 메일을 받으면 바로 돈이 들어오나요?** |
| :--- |
| A2. 접수 확인과 처리 결과는 별도입니다. 승인 결과와 선택한 환불 수단의 반영 상태를 확인하세요. |

| **Q3. 할인 직전에 산 게임을 환불하고 다시 살 수 있나요?** |
| :--- |
| A3. Steam은 바로 다음 날 할인되는 게임을 환불 후 재구매하는 것을 남용으로 보지 않는다고 안내합니다. 개별 환불 조건은 확인해야 합니다. |
