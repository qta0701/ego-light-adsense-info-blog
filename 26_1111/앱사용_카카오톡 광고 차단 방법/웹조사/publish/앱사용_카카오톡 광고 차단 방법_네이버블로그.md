## 2. 채널 메시지와 알림톡 조정하기

광고를 보낸 채팅방을 열고 상단의 홈 아이콘을 선택해 채널 프로필로 이동하세요. 추가한 채널이라면 프로필에서 채널 차단을 선택할 수 있어요.

친구로 추가하지 않은 채널의 알림톡에는 채팅방 상단에 차단 버튼이 표시될 수 있습니다. 알림톡은 광고뿐 아니라 거래 정보를 전달하기도 하므로 내용을 먼저 확인하세요.

| 💬 메시지 | 🔍 확인할 곳 | ⚠️ 차단 전 체크 |
| :---: | :---: | :---: |
| 채널 광고 | 채팅방 상단 홈 → 채널 프로필 | 차단할 채널이 맞는지 확인 |
| 알림톡 | 채팅방 상단의 차단 버튼 | 배송·결제 안내 수신 여부 확인 |

채널을 차단해도 해당 업체가 보내는 문자 메시지 수신 설정까지 자동으로 바뀌는 것은 아니에요. 문자 광고가 계속된다면 해당 업체의 수신 동의도 별도로 살펴보세요.

## 3. 채팅 목록 배너를 잠시 숨기는 방법

[이미지 배치 지시: `01_official-print.png` - 카카오 비즈보드 광고와 노출 빈도 조정 안내 삽입. 캡션: "카카오 비즈보드 광고와 노출 빈도 조정 안내"]

카카오 안내에 따르면 Android에서는 채팅 목록의 광고 항목을 길게 누른 뒤 **이 광고 보지 않기**를 선택합니다. 아이폰에서는 광고 항목을 스와이프하고 **숨김**을 선택해요.

| 📱 기기 | 👆 조작 순서 | ⏱️ 결과 |
| :---: | :---: | :---: |
| Android | 광고 길게 누르기 → 이 광고 보지 않기 | 해당 광고 약 하루 숨김 |
| iPhone | 광고 스와이프 → 숨김 | 해당 광고 약 하루 숨김 |

숨긴 뒤에도 다른 광고가 보일 수 있어요. 카카오는 광고 영역을 영구적으로 없애는 설정을 제공하지 않으며, 일부 기본광고에는 숨김이 적용되지 않는다고 안내합니다.

## 4. 맞춤형 광고 설정과 기기 설정 확인

[이미지 배치 지시: `02_official-print.png` - Android·iOS의 기기 식별자 설정 안내 삽입. 캡션: "Android·iOS의 기기 식별자 설정 안내"]

[이미지 배치 지시: `03_official-print.png` - 카카오 맞춤형 광고의 동의·거부 선택 삽입. 캡션: "카카오 맞춤형 광고의 동의·거부 선택"]

카카오 맞춤형 광고 안내에서 이용자 통제권 설정을 확인해 차단 여부를 선택할 수 있어요. 기기에서도 광고 식별자 관련 설정을 확인할 수 있습니다.

| ⚙️ 설정 위치 | 🧭 공식 안내의 경로 |
| :---: | :---: |
| Android | 설정 → Google → 광고 → 광고 ID 삭제 |
| iPhone | 설정 → 개인정보 보호 → 추적 → 앱의 추적 요청 허용 끄기 |

기기 버전에 따라 메뉴 이름이나 위치는 달라질 수 있어요. 이 설정은 맞춤형 광고를 제한하는 방법이며 모든 광고를 없애는 기능은 아닙니다.

브라우저 쿠키를 삭제하면 웹에서 선택한 맞춤형 광고 설정이 다시 허용 상태로 바뀔 수 있으니, 삭제한 뒤 설정을 한 번 더 확인해 보세요.
