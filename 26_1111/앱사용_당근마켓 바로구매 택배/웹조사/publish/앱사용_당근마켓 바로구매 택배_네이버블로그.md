## 3. 포장 규격과 택배비 확인

[이미지 배치 지시: `daangn-delivery-marked.png` - 당근 바로구매 택배 규격과 배송 유의사항 삽입. 캡션: "당근 바로구매 택배 규격과 배송 유의사항"]

당근 고객센터는 택배 규격으로 세 변의 합 160cm 이하, 20kg 이하 등을 안내합니다. 내용물이 움직이지 않도록 완충재를 넣고 파손 위험이 큰 물품이나 취급 불가 물품인지도 확인하세요.

| 📦 항목 | ⚠️ 주의할 점 |
| :---: | :---: |
| 크기·무게 | 세 변 합 160cm 이하, 20kg 이하 등 규격 확인 |
| 포장 단위 | 게시글 한 건의 물품은 한 박스로 발송 |
| 여러 거래 | 여러 게시글의 물품을 한 박스에 합치지 않기 |
| 결제 금액 | 구매자가 배송지 입력 후 택배비·수수료 확인 |

같은 구매자가 여러 물품을 샀더라도 게시글별 물품을 한 상자에 합치지 마세요. 배송비와 수수료는 변동될 수 있으니 실제 결제 화면의 금액을 기준으로 확인합니다.

## 4. 취소와 배송 후 문제 신고

수거일 지정 전에는 구매자와 판매자가 각각 직접 취소할 수 있습니다. 지정 후 수거 전날까지는 구매자가 판매자에게 취소를 요청할 수 있고, 판매자가 거절하면 거래가 계속될 수 있어요.

| 🚚 거래 단계 | 🧭 확인할 처리 |
| :---: | :---: |
| 수거일 지정 전 | 거래 상세에서 직접 취소 가능 |
| 지정 후 수거 전날까지 | 구매자는 취소 요청, 판매자는 직접 취소 가능 |
| 수거 당일·배송 중 | 직접 취소 제한 또는 불가, 거래 상태 확인 |
| 배송 완료 후 | 구매확정 전 문제 신고와 보류 확인 |

배송 완료 후 물품이 파손되었거나 설명과 다르다면 곧바로 구매확정을 누르지 말고 거래 채팅방의 **물품에 문제가 있어요**를 확인하세요. 당근은 배송 완료 후 48시간이 지나면 자동 구매확정된다고 안내합니다.
