## 3. 구간이나 일행이 달라질 때

출발역이나 도착역을 바꾸는 경우는 같은 구간의 단순 변경과 달라요. 새 구간의 잔여석과 기존 표의 반환 예상액을 먼저 확인한 뒤 반환·재예매를 검토하거나 역 창구에 문의하세요.

| 👥 상황 | 🧭 먼저 확인할 것 |
| :---: | :---: |
| 출발역·도착역 변경 | 새 구간의 좌석과 기존 표 반환 조건 |
| 일행 일부만 변경 | 반환 화면에서 해당 인원만 선택할 수 있는지 |
| 묶음 상품 | 일부 반환이 남은 일행에게 미치는 영향 |

특히 여러 명이 한 상품으로 묶여 있다면 기존 표를 반환하기 전에 처리 범위를 확인하는 것이 좋아요. 새 좌석이 남아 있는지도 함께 살펴보세요.

## 4. 출발 직전이나 출발 후에는?

출발까지 30분이 채 남지 않았다면 앱의 일반 변경 기한을 지난 상태예요. 역 창구에 변경 가능 여부를 문의하거나, 반환 후 재예매할 때 표시되는 위약금과 잔여석을 확인하세요.

| ⏰ 상황 | 📌 처리 전 확인 |
| :---: | :---: |
| 출발 전 30분 미만 | 창구 문의 또는 반환 예상액·새 좌석 확인 |
| 출발 후 | 반환 가능 기한과 미탑승 확인 여부 확인 |
| 앱 반환이 어려움 | 승차권을 가지고 역 창구에 문의 |

코레일 FAQ는 미탑승이 확인되는 코레일톡 승차권을 출발 후 10분 이내 앱에서 반환할 수 있다고 안내합니다. 이 기한이 위약금 면제를 뜻하는 것은 아니니 반환 화면의 금액도 확인하세요.
