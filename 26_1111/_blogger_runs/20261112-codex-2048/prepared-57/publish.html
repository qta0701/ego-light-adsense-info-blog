App Store에서 실수로 앱이나 게임 아이템을 구입했거나 무료 체험이 끝나 구독료가 청구됐다면, Apple 문제 신고에 결제에 사용한 Apple 계정으로 로그인하세요. ‘환불 요청’을 선택하고 사유와 구입 항목을 고른 뒤 제출하면 됩니다. Apple은 일부 구입 건을 환불 대상으로 안내하며, 적합 여부는 국가나 지역에 따라 달라질 수 있습니다.

구독료 환불을 요청할 때 다음 갱신도 멈추려면 기기에서 구독 취소도 진행하세요. 결제 항목이 화면에 없다면 먼저 영수증과 결제 계정을 확인하세요.

영수증에서 결제 계정을 확인했다면 Apple 문제 신고 페이지에서 해당 구입 항목을 찾으세요.

Apple 문제 신고 페이지 열기

애플 환불 요청 방법

1. 구입할 때 사용한 Apple 계정으로 로그인

iPhone의 Safari나 PC·Mac의 브라우저에서 Apple 문제 신고 페이지를 열고 구입에 사용한 계정으로 로그인합니다. Apple 계정을 여러 개 쓰거나 가족 공유로 결제했다면 영수증에 적힌 구입 항목과 계정부터 대조하면 찾기 쉽습니다.

2. 환불 요청과 사유 선택

‘무엇을 도와드릴까요?’ 아래 ‘문제 선택’에서 ‘환불 요청’을 고릅니다. 이어서 ‘세부 내용 선택’에서 결제 상황에 맞는 사유를 선택하고 ‘다음’을 누릅니다.

‘다음’을 누르면 환불을 요청할 구입 항목을 선택하는 화면으로 이동합니다.

3. 구입 항목을 선택하고 제출

환불받으려는 앱, 구독 또는 인앱 결제 항목을 선택한 뒤 ‘제출’을 누릅니다. 같은 앱에서 구입하거나 갱신한 내역이 여러 건이라면 제출 전에 영수증의 구입 항목과 금액을 대조하세요. 접수 후 업데이트가 오기까지 Apple은 24~48시간을 안내합니다. 요청 상태와 실제 환급 기간도 확인할 수 있습니다.

영수증이 있는 경우

이메일에서 ‘Apple 영수증’ 또는 ‘Apple 송장’을 검색합니다. 카드 명세서의 청구 금액과 일치하는 영수증을 찾아 구입 항목과 Apple 계정을 확인하세요.

  • 내 다른 Apple 계정으로 결제한 경우에는 영수증에 표시된 계정으로 문제 신고 페이지에 다시 로그인합니다.
  • 가족 공유 대표자가 공유 결제 수단으로 청구된 건을 찾는 경우에는 문제 신고 페이지에서 Apple 계정 버튼을 누른 뒤 ‘모두’를 선택합니다. 공유 결제 수단으로 청구된 구입 내역이 표시됩니다.

기기에서도 거래를 대조할 수 있습니다. iPhone에서는 App Store의 프로필에서 ‘앱 및 구입 내역’ → ‘구입 내역’으로 들어가 금액을 검색합니다. 오래된 거래라면 ‘최근 90일’ 필터에서 기간을 바꿉니다. Apple 구입 내역 안내

  • 청구가 보류 중이면 이메일 영수증을 받은 뒤 환불 요청을 다시 시도하세요.
  • 미결제 주문이 있으면 그 주문을 먼저 결제해야 합니다. 필요한 경우 Apple 계정의 결제 정보를 업데이트하세요.
  • 개발사 웹사이트나 다른 회사를 통한 직접 결제라면 카드·은행 명세서에서 청구한 업체를 확인하고 해당 업체에 환불을 문의하세요.

다음 결제를 막는 Apple 구독 취소 방법

환불 요청은 이미 청구된 금액에 대한 절차입니다. 더 이상 이용하지 않을 구독은 아래 기기별 경로에서 취소해 다음 갱신을 막으세요.

iPhone·iPad 설정에서 구독 취소

설정 앱을 열고 화면 상단의 사용자 이름을 누른 뒤 ‘구독’을 엽니다.

목록에서 해당 구독을 누르고 ‘구독 취소’를 선택합니다. 버튼이 보이지 않으면 아래로 스크롤해 보세요. 취소 버튼이 없거나 만료 안내가 빨간 글씨로 표시된다면 Apple은 이미 취소된 상태라고 안내합니다.

Mac App Store에서 구독 취소

Mac의 App Store에서 사이드바 아래의 사용자 이름을 클릭합니다. 열린 페이지에서 이름을 다시 클릭해 Apple 계정 화면을 연 뒤 ‘구독(Subscriptions)’으로 들어갑니다.

취소할 항목을 선택한 뒤 ‘구독 취소’를 클릭합니다.

Windows용 Apple Music·Apple TV에서 구독 취소

앱 사이드바 하단에서 사용자 이름 → ‘나의 계정 보기’를 선택합니다. ‘설정’으로 스크롤해 ‘구독’ 옆의 ‘관리’를 누른 뒤, 해당 구독의 ‘수정’ → ‘구독 취소’를 선택합니다.

가족 구성원의 계정이 구독 영수증에 표시된다면, 그 구성원이 자신의 Apple 계정에서 구독을 취소해야 합니다.

환불 상태 조회와 결제 수단별 반영 기간

제출 후 Apple의 업데이트까지는 24~48시간을 예상하세요. Apple 문제 신고에서 요청한 계정으로 로그인한 뒤 ‘요청 상태 확인’을 선택하고 ‘대기 중’을 누르면 진행 상황을 볼 수 있습니다. ‘요청 상태 확인’이 표시되지 않으면 해당 계정에 처리 대기 중인 환불 요청이 없는 상태입니다.

승인된 금액은 원래 결제 수단으로 돌아갑니다. 승인 후 명세서나 계정에 표시되기까지 걸리는 시간은 결제 수단별로 다릅니다.

결제 수단승인 후 반영 기간

휴대전화 결제의 진행 상황은 이동통신사에 문의하세요. 카드 등으로 결제했고 30일 뒤에도 환불액이 명세서에 표시되지 않으면 결제에 사용한 금융기관에 문의하세요.
