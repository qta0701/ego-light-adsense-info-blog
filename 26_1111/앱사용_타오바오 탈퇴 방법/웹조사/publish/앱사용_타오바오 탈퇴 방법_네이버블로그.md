# 타오바오 탈퇴 방법｜앱에서 계정 삭제 전 확인할 것

타오바오 탈퇴는 앱의 계정 및 보안 메뉴에서 계정 탈퇴 항목을 찾아 신청할 수 있어요. 신청 전 미완료 주문과 환불부터 확인하세요.

중국어 화면이라면 **注销**라는 글자를 찾고, 마지막 확인 화면의 조건을 충분히 읽어 보세요.

탈퇴 후 필요한 주문 기록을 다시 찾기 어려울 수 있으니 신청 전에 필요한 정보를 챙겨 두면 좋아요.

## 1. 탈퇴 전에 주문과 계정 상태 확인

[이미지 배치 지시: `01_official-print.png` - 타오바오 계정 해지 전 거래·분쟁·미납 확인 안내 삽입. 캡션: "타오바오 계정 해지 전 거래·분쟁·미납 확인 안내"]

2026년 11월 13일 확인한 타오바오 공식 안내는 계정이 정상 상태이고 미완료 거래, 진행 중인 분쟁·제재, 미납금이 없어야 한다고 설명합니다.

| 🔍 확인 항목 | ✅ 먼저 할 일 |
| :---: | :---: |
| 주문·배송 | 아직 받지 못한 상품이 있는지 확인 |
| 반품·환불 | 진행 중인 처리가 끝났는지 확인 |
| 분쟁·미납 | 신고·제재와 결제 의무가 남았는지 확인 |
| 기록 | 나중에 필요한 주문번호·결제 증빙 보관 |

배송을 받았더라도 반품이나 환불이 끝나지 않았다면 처리 상태를 먼저 확인하세요. 연결된 알리페이와 관련된 미해결 의무도 살펴보는 것이 좋아요.

신청 전에 대상 계정과 처리 결과를 확인하면 사용 중인 다른 계정과 혼동하는 실수를 줄일 수 있습니다.

## 2. 앱에서 중국어 탈퇴 메뉴 찾기

[이미지 배치 지시: `taobao-app-route-marked.png` - 알리바바 공식 문서의 타오바오 앱 탈퇴 메뉴 삽입. 캡션: "알리바바 공식 문서의 타오바오 앱 탈퇴 메뉴"]

탈퇴할 계정으로 타오바오 앱에 로그인한 뒤 **我的淘宝 → 设置 → 账户与安全 → 注销账户** 순서로 확인합니다. 공식 문서에 나온 메뉴 경로이며, 앱 버전에 따라 표기가 달라질 수 있어요.

| 📱 중국어 메뉴 | 🇰🇷 뜻 |
| :---: | :---: |
| 我的淘宝 | 마이 타오바오 |
| 设置 | 설정 |
| 账户与安全 | 계정 및 보안 |
| 注销账户 | 계정 탈퇴 |

계정이라는 말이 **账户** 대신 **账号**로 표시될 수도 있습니다. 본인의 화면에서 탈퇴할 계정이 맞는지 확인하고 안내되는 조건을 읽은 뒤 진행하세요.

## 3. 신청 화면에서 확인할 내용

[이미지 배치 지시: `taobao-after-closure-marked.png` - 타오바오 계정 탈퇴 후 서비스 종료 안내 삽입. 캡션: "타오바오 계정 탈퇴 후 서비스 종료 안내"]

계정 탈퇴는 단순 로그아웃과 달리 기존 계정과 기록에 영향을 줄 수 있어요. 공식 안내는 신청을 제출한 뒤 철회를 요구하지 않는다는 조건을 포함하므로 최종 단계에서 내용을 충분히 확인하세요.

| ⚠️ 확인할 결과 | 📝 살펴볼 점 |
| :---: | :---: |
| 서비스 이용 | 해당 계정으로 다시 로그인할 수 없는지 |
| 기록 | 필요한 주문·거래 자료를 따로 저장했는지 |
| 혜택 | 계정에 남은 쿠폰·포인트가 있는지 |
| 연동 서비스 | 별도 결제·서비스의 미해결 의무가 있는지 |

실제 계정의 마지막 확인 화면과 처리 시간은 직접 확인하지 않았어요. 화면에 표시되는 계정별 조건을 우선 확인하고 이해하기 어려우면 신청을 서두르지 마세요.

## 4. 탈퇴 메뉴가 보이지 않을 때

[이미지 배치 지시: `google-official-marked.png` - Google 검색에서 실제로 연 공식 결과 · 淘宝账号注销重要提醒 삽입. 캡션: "Google 검색에서 실제로 연 공식 결과 · 淘宝账号注销重要提醒"]

앱을 업데이트한 뒤에도 메뉴가 다르거나 계정에 로그인할 수 없다면 타오바오 공식 고객센터에서 계정 접근 복구와 탈퇴 가능 여부를 문의하세요.

| 🧩 상황 | 🧭 먼저 확인할 방법 |
| :---: | :---: |
| 메뉴가 다름 | 설정의 계정·보안 항목과 앱 버전 확인 |
| 로그인 불가 | 공식 계정 복구 절차 확인 |
| 탈퇴 조건 미충족 | 주문·분쟁·미납 상태 확인 |
| 결제 서비스 연동 | 해당 서비스의 별도 관리 조건 확인 |

비밀번호나 인증번호를 타인에게 전달하지 말고 공식 앱과 고객센터 경로에서만 계정 상태를 확인하세요.

## 5. 자주 묻는 질문

| **Q1. 앱을 삭제하면 타오바오 계정도 탈퇴되나요?** |
| :--- |
| A1. 앱 삭제와 계정 탈퇴는 별개입니다. 계정 탈퇴는 공식 메뉴에서 조건을 확인하고 신청해야 합니다. |

| **Q2. 주문한 물건이 아직 배송 중이어도 탈퇴할 수 있나요?** |
| :--- |
| A2. 공식 안내는 미완료 거래가 없어야 한다고 설명합니다. 배송과 관련 처리가 끝났는지 먼저 확인하세요. |

| **Q3. 탈퇴하면 알리페이도 자동으로 해지되나요?** |
| :--- |
| A3. 연결된 서비스의 해지 여부를 자동으로 단정하지 말고 각 서비스의 계정과 미해결 의무를 따로 확인하세요. |
