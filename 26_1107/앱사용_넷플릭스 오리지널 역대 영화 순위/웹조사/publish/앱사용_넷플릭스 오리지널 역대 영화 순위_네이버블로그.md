## 4. 자주 묻는 질문 (FAQ) ❓

| **Q1. 영어 영화와 비영어 영화를 합친 단 하나의 통합 1위는 없나요?** |
| :--- |
| A1: 넷플릭스 공식 시스템은 문화적 다양성과 언어적 접근성을 존중하기 위해 영어 영화(Movies | English)와 비영어 영화(Movies | Non-English)를 공식적으로 분리하여 발표해요. 따라서 두 차트의 수치를 임의로 섞지 않고 각 부문별 순위로 이해하시는 것이 정확해요. |

| **Q2. 넷플릭스가 적용하는 '공개 후 첫 91일 룰'이란 무엇인가요?** |
| :--- |
| A2: 오래전에 공개된 작품이 누적 시간만으로 계속 1위를 독점하는 불공정을 막기 위해, 모든 오리지널 작품이 공개된 첫날부터 91일(약 3개월) 동안 기록한 시청 시간만을 집계하여 순위를 매기는 넷플릭스만의 공정한 글로벌 흥행 평가 기준이에요. |

| **Q3. 차트에 표시된 조회 수(Views)는 영화를 끝까지 다 본 사람 수인가요?** |
| :--- |
| A3: 아니에요. 넷플릭스의 공식 Views는 전 세계 이용자들의 '총 시청 시간'을 해당 영화의 '상영 시간(러닝타임)'으로 나눈 환산 수치예요. 특정 시청자 한 명이 여러 번 돌려봤거나 여러 명이 조금씩 끊어봤더라도 공정하게 시간 기준으로 표준화된 지표랍니다. |
