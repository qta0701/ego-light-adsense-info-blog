직접 계좌 송금은 사기 위험이 매우 높을 뿐 아니라 번개장터 거래 보호 대상에서 전면 제외되므로 공식 정책을 반드시 숙지해야 해요.

## 1. 번개장터 직접 계좌거래와 거래 보호 제외 규정

[이미지 배치 지시: `02_guide.png` - 번개장터 공식 고객센터의 직접 계좌이체 거래 보호 대상 제외 경고 안내 화면 삽입. 캡션: "번개장터 직접 계좌이체 거래 보호 제외 공식 안내"]

번개장터 고객센터 공식 FAQ의 '현금거래(직접 계좌이체)를 하면 어떻게 되나요?' 문서를 살펴보면 매우 엄격한 경고 문구가 명시되어 있어요.

판매자가 개인 계좌번호를 알려주며 입금을 유도하더라도, 플랫폼 밖에서 이루어진 송금은 번개장터 구매자 보호 프로그램의 대상이 되지 않는답니다.

즉 돈을 먼저 보낸 뒤 판매자가 잠적하거나 엉뚱한 물건을 보내더라도 번개장터 시스템을 통해서는 결제 취소나 환불 보상을 받을 수 없어요.

| **직접 계좌이체 시 노출되는 결정적 위험 요소** ⚠️ |
| :--- |

- 💸 **피해 구제 불가**: 문제 발생 시 번개장터 분쟁 조정 및 결제 대금 보호 혜택을 전혀 받을 수 없어요.
- 🔗 **피싱 링크 사기**: 안전결제창을 사칭한 가짜 외부 결제 URL로 유인해 추가 금전을 갈취하는 수법이 성행하고 있어요.
- 🚫 **당사자 합의 무효**: 두 사람이 서로 동의하여 계좌이체를 했더라도 시스템 적발 시 제재 대상이 돼요.

## 2. 안전결제 의무화 정책과 제재 대상이 되는 거부 사례

[이미지 배치 지시: `04_guide.png` - 번개장터 고객센터의 안전결제 거부 간주 사례 목록 화면 삽입. 캡션: "안전결제 거부로 간주되는 대표적 위반 사례"]

현재 번개장터는 중고거래 사기를 원천 차단하기 위해 모든 상품 거래를 안전결제로 진행하도록 정책을 전면 의무화하여 운영하고 있어요.

따라서 직접 계좌번호를 불러주는 행위뿐만 아니라 안전결제를 우회하려는 다양한 시도가 모두 '안전결제 거부'로 분류되어 엄격한 제재를 받아요.

번개톡 모니터링 시스템이나 상대방의 신고로 정책 위반이 확인되면 경고 없이 계정이 영구 정지될 수 있으니 각별히 유의하셔야 해요.

| **안전결제 거부로 간주되는 5대 대표 위반 유형** 🚫 |
| :--- |

| 위반 유형 🚫 | 구체적 사례 💬 | 운영진 제재 조치 ⚖️ |
| :--- | :--- | :--- |
| 💵 현금 계좌이체 유도 | "수수료 빼드릴 테니 제 계좌로 송금해 주세요" | 1차 경고 및 서비스 이용 정지 |
| 🔗 외부 결제 사이트 링크 유인 | 카카오페이 송금 링크나 가짜 안전결제 URL 전송 | 사기 의심 계정으로 즉시 영구 차단 |
| ➕ 안전결제 시 추가금 요구 | "안전결제 하시려면 수수료 3.5% 더 입금하세요" | 거래 취소 처리 및 판매 자격 제한 |
| 📦 배송 전 구매확정 강요 | "택배 부치기 전에 먼저 구매확정 눌러주셔야 보내요" | 거래 분쟁 접수 및 정산 보류 조치 |
| 🚫 번개케어/안전결제 일방 거부 | 정당한 사유 없이 안전결제 요청 글을 일방 삭제 | 게시글 삭제 및 판매글 등록 제한 |

이러한 행위는 단순히 수수료를 아끼려는 편법이 아니라 거래 질서를 해치는 명백한 이용약관 위반에 해당해요.

구매자 입장에서도 판매자가 이런 요구를 해온다면 절대 응하지 마시고 번개톡 대화창 내의 [신고하기]를 통해 즉시 접수하셔야 해요.

## 3. 직접 번개장터 거래를 진행하며 겪은 경험담과 팁

[이미지 배치 지시: `05_guide.png` - 번개장터 안전결제 권고 및 공식 FAQ 질문 목록 화면 삽입. 캡션: "번개장터 안전결제 이용 권고 및 고객센터 안내 화면"]

제가 직접 스마트워치를 번개장터에서 구매하려고 판매자에게 번개톡을 보냈을 때, 판매자가 "오늘 바로 우체국 택배로 부쳐줄 테니 번개페이 수수료만큼 깎아서 계좌로 보내달라"고 제안을 해왔던 적이 있었어요. 순간 가격이 저렴해져서 솔깃했지만 번개장터 공식 이용약관과 고객센터 문서를 꼼꼼히 대조해보니 직접 계좌 거래는 사기를 당해도 플랫폼 차원의 구제가 일체 불가능하더라구요.

그래서 정중하게 "저는 조금 더 비용이 들더라도 번개장터 안전결제로만 거래하고 싶다"고 말씀드렸더니, 그 즉시 상대방이 대화방을 나가버리고 며칠 뒤 다른 피해자들에 의해 사기 계정으로 신고되어 차단된 것을 확인했어요. 만약 판매자의 달콤한 수수료 할인 유혹에 넘어가 계좌로 돈을 보냈다면 그대로 수십만 원의 금전적 피해를 볼 뻔했던 아찔한 순간이었답니다.

이후로는 아무리 매력적인 가격이라도 판매자가 계좌이체를 요구하면 뒤도 돌아보지 않고 거래를 중단하는 저만의 원칙을 세웠어요. 공식 번개장터 안전결제 시스템을 이용하면 물건이 도착해 정상 작동하는지 확인한 뒤에야 판매자에게 대금이 정산되므로, 몇천 원의 수수료보다 내 소중한 자산을 안전하게 지키는 것이 훨씬 현명한 선택이에요.

## 4. 자주 묻는 질문 (FAQ) ❓

| **Q1. 구매자가 먼저 계좌이체로 입금하겠다고 해도 판매자가 처벌받을 수 있나요?** |
| :--- |
| A1: 네, 구매자가 먼저 제안했더라도 판매자가 이에 응해 계좌번호를 전달하고 현금 거래를 진행하면 안전결제 거부 정책 위반으로 두 사람 모두 서비스 이용 정지 페널티를 받을 수 있어요. 모든 거래는 공식 안전결제 절차를 거치셔야 안전해요. |

| **Q2. 판매자가 보낸 안전결제 링크를 눌렀는데 네이버페이나 별도 결제창이 뜨면 사기인가요?** |
| :--- |
| A2: 100% 전형적인 피싱 사기 수법이에요! 번개장터의 공식 안전결제는 번개톡 화면 내부의 [안전결제] 버튼을 통해서만 진행되며, 판매자가 채팅창으로 외부 인터넷 링크(URL)를 보내는 경우는 일체 없으니 절대 개인정보나 금융정보를 입력하시면 안 돼요. |

| **Q3. 이미 상대방 계좌로 송금했는데 연락이 끊겼다면 어떻게 대처해야 하나요?** |
| :--- |
| A3: 직접 계좌 송금은 번개장터의 보상 대상이 아니므로, 즉시 대화 내역 캡처본과 계좌 이체 확인증을 챙겨 경찰청 사이버범죄수사과(cyberbureau.police.go.kr) 또는 가까운 경찰서에 사기죄로 정식 고소 접수를 진행하셔야 해요. |
