# 코레일 승차권 조회 방법: 회원·비회원 확인 경로

코레일 승차권 조회는 예매할 때 **회원이었는지 비회원이었는지**에 따라 경로가 달라요.

비회원이라면 간편인증으로 예매했는지도 먼저 확인해 보세요.

| 🚆 예매한 승차권 확인 순서 살펴보기 |
| --- |

https://how.supportimes.com/2026/11/blog-post.html

## 1. 예매한 방식부터 확인하세요

[이미지 배치 지시: `01_01_search.png` - 코레일 공식 승차권 확인 검색 결과 삽입. 캡션: "코레일 공식 승차권 확인 경로 찾기"]

[이미지 배치 지시: `08_main_entry_marked.png` - 코레일 홈페이지 승차권 확인 메뉴 삽입. 캡션: "코레일 홈페이지의 승차권 확인 메뉴"]

이미 구입한 표를 보려면 새 열차를 찾는 예매 화면이 아니라 **승차권 확인** 메뉴를 선택해요. 코레일 웹사이트에서 회원과 비회원의 확인 방법을 구분해 안내합니다.

| 예매 방식 | 확인 경로 |
| --- | --- |
| 👤 회원 | 승차권 확인에서 회원 로그인 |
| 📱 비회원 간편인증 | 비회원 확인에서 간편인증 선택 |
| 📝 기존 비회원 | 이름·휴대폰 번호·비밀번호로 확인 |

아래 화면은 2026년 11월 13일 확인한 웹 화면이에요. 개인 계정 로그인이나 실제 승차권 조회는 진행하지 않았습니다.

## 2. 회원으로 예매했다면

[이미지 배치 지시: `02_02_login.png` - 코레일 회원 로그인 화면 삽입. 캡션: "회원 승차권 확인을 위한 로그인 화면"]

코레일 승차권예매 사이트에서 **승차권 → 승차권 확인**으로 이동한 뒤 제공되는 회원번호, 이메일 주소 또는 휴대폰 번호 방식 중 하나를 선택해 로그인해요.

| 순서 | 확인할 내용 |
| --- | --- |
| ① 🎫 | 승차권 확인 메뉴 선택 |
| ② 🔐 | 회원번호·이메일·휴대폰 번호 중 로그인 방식 선택 |
| ③ 📋 | 로그인 후 승차권 확인 화면 살펴보기 |

번호나 비밀번호가 기억나지 않으면 로그인 화면의 찾기 기능을 사용하세요. 화면에 다섯 차례 실패 시 로그인 제한 안내가 있으므로 계정 정보를 반복해서 추측하지 않는 편이 좋아요.

## 3. 비회원으로 예매했다면

[이미지 배치 지시: `03_06_method_clean.png` - 비회원 확인 방식 선택 화면 삽입. 캡션: "간편인증과 기존 비회원 확인 방식 선택"]

[이미지 배치 지시: `04_07_form_clean.png` - 기존 비회원 확인 입력 화면 삽입. 캡션: "기존 비회원 승차권 확인 입력 항목"]

비회원 확인 화면에서는 **간편인증** 또는 **기존 비회원 승차권 확인** 중 예매 당시 사용한 방식에 맞게 골라요. 간편인증으로 예매한 승차권은 간편인증으로만 조회할 수 있다는 안내가 표시됩니다.

| 방식 | 필요한 확인 |
| --- | --- |
| 🔑 간편인증 | 예매에 사용한 간편인증 방식으로 조회 |
| 📱 기존 비회원 | 예약자 이름, 휴대폰 번호, 비밀번호 5자리 입력 |
| 💬 전달받은 표 | 비밀번호를 코레일 알림톡 또는 문자에서 확인 |

기존 비회원 화면에서 조회되지 않는다면 예매할 때 간편인증을 썼는지 먼저 돌아보세요. 그래도 확인이 어렵다면 코레일 대표전화 1588-7788 또는 공식 고객센터에 문의할 수 있어요.

| **간편인증으로 예매한 표를 기존 비회원 화면에서 볼 수 있나요?** |
| --- |
| 공식 화면은 간편인증으로 예매한 승차권을 간편인증으로만 조회할 수 있다고 안내합니다. |
