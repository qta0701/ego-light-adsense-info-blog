# 하나은행 환율조회 방법: 날짜·회차 선택과 환율표 읽기

하나은행 환율은 공식 홈페이지의 **외환 → 환율/외화예금 금리 → 현재환율**에서 확인할 수 있어요.

숫자를 보기 전에 통화 단위와 현찰·송금 열을 먼저 구분해 보세요.

## 1. 현재환율 조회 화면으로 이동

[이미지 배치 지시: `01_search.png` - 하나은행 공식 환율 검색 결과 삽입. 캡션: "하나은행 공식 환율 조회 페이지 찾기"]

[이미지 배치 지시: `02_guide.png` - 통화·일자·고시회차 선택 화면 삽입. 캡션: "통화와 날짜, 고시회차 선택 후 조회"]

공식 홈페이지에서 현재환율 화면을 열고 원하는 통화와 일자, 최초·현재·특정 고시회차 중 필요한 항목을 선택한 뒤 **조회**를 눌러요. 일자를 직접 입력할 때는 화면에서 안내하는 연월일 8자리 형식을 확인하세요.

| 선택 항목 | 확인할 내용 |
| --- | --- |
| 💵 통화 | 원하는 통화 또는 기본 선택 상태 확인 |
| 📅 일자 | 달력 또는 연월일 8자리 입력 안내 확인 |
| 🔢 고시회차 | 최초·현재·특정회차 중 필요한 기준 선택 |

이 화면은 2026년 11월 13일 로그인 없이 확인한 PC 화면이에요. 캡처 속 숫자는 당시 예시이며 현재 환율이 아닙니다.

## 2. 현찰과 송금 열을 구분하세요

[이미지 배치 지시: `03_guide.png` - 고시일시와 환율표 열 안내 삽입. 캡션: "현찰·송금·매매기준율 열 구분"]

결과를 볼 때는 기준일, 고시일시와 회차, 조회시각부터 확인해요. 같은 날이라도 회차가 다르면 숫자가 달라질 수 있습니다.

| 거래 목적 | 확인할 열 |
| --- | --- |
| 💴 외화를 지폐로 살 때 | 현찰 사실 때 |
| 💵 외화 지폐를 팔 때 | 현찰 파실 때 |
| 🌐 해외로 보내거나 받을 때 | 송금 보낼 때 또는 받을 때 |
| 📊 기준값 비교 | 매매기준율과 통화 단위 |

일본 엔화는 표에 **JPY (100)**으로 표시되므로 다른 통화와 숫자만 비교하지 말고 단위를 함께 보세요. 매매기준율을 실제 거래금액으로 그대로 가정하지 말고 우대와 수수료가 반영된 최종 거래 화면을 확인해야 해요.

## 3. 과거 날짜와 휴일 조회 시 확인

[이미지 배치 지시: `04_guide.png` - 휴일과 고시회차 유의사항 삽입. 캡션: "휴일 환율 조회와 고시 유의사항"]

과거 고시를 볼 때는 일자와 회차를 지정하고 결과의 기준일과 고시일시를 함께 기록해 두면 비교하기 좋아요. 공식 유의사항은 주말·공휴일 또는 영업일 첫 고시 전에는 전 영업일 기준으로 조회될 수 있고, 시장 상황에 따라 휴일에도 재고시될 수 있다고 설명합니다.

| 상황 | 다시 확인할 점 |
| --- | --- |
| 📆 예상한 날짜와 다름 | 일자·회차와 결과의 기준일·고시일시 |
| 🔍 통화가 보이지 않음 | 선택한 통화·날짜와 해당 통화 고시 여부 |
| 💱 실제 환전 예정 | 현찰 거래 열과 최종 거래 화면의 환율·수수료 |

이번 조사에서 USD를 선택해 조회했지만 결과표가 해당 통화만으로 갱신되는 모습은 확인하지 못했어요. 조회 결과의 선택 상태를 직접 확인한 뒤 사용하세요.

## 4. 자주 묻는 질문

| **현금으로 달러를 살 때 어떤 숫자를 보나요?** |
| --- |
| 환율표의 현찰 사실 때 열을 확인하고, 실제 거래에서는 우대와 수수료가 반영된 최종 화면도 살펴보세요. |

| **엔화는 왜 단위를 확인해야 하나요?** |
| --- |
| 확인한 표는 일본 엔화를 JPY (100)으로 표시합니다. 통화 옆 기준 단위를 함께 읽어야 합니다. |

| **휴일에 조회한 날짜가 다를 수 있나요?** |
| --- |
| 은행 안내에 따르면 휴일이나 영업일 첫 고시 전에는 전 영업일 기준으로 조회될 수 있습니다. 결과의 기준일과 고시일시를 확인하세요. |
