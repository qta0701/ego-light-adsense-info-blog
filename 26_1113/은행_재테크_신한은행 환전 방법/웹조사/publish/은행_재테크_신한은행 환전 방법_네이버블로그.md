## 2. PC에서 인터넷환전 신청으로 이동

[이미지 배치 지시: `02_guide.png` - 인터넷환전신청 진입 화면 삽입. 캡션: "신한은행 환전가이드의 인터넷환전신청"]

[이미지 배치 지시: `03_guide.png` - PC 신청 로그인 선택 화면 삽입. 캡션: "인터넷환전 신청의 로그인 수단 선택"]

개인뱅킹의 **금융상품 → 외환 → 환전 → 환전가이드**에서 인터넷환전신청을 선택해요. 확인 당시 금융인증서·공동인증서와 쏠패스 로그인 화면으로 이동했습니다.

| 순서 | 확인할 내용 |
| --- | --- |
| ① 🌐 | 공식 환전가이드에서 인터넷환전신청 선택 |
| ② 🔐 | 본인에게 맞는 로그인 수단 선택 |
| ③ ✅ | 신청 화면에서 통화·금액·환율·수령 장소와 날짜 확인 |

인증 이후 입력 화면은 직접 확인하지 못했어요. 은행 화면의 현재 안내를 따르고 거래를 확정하기 전 최종 원화 금액을 다시 살펴보세요.

## 3. 모바일 신청과 외화 수령 시 주의

[이미지 배치 지시: `05_guide.png` - 신한은행 모바일 환전 대상 안내 삽입. 캡션: "쏠편한 환전 대상과 수령 방식 안내"]

[이미지 배치 지시: `06_guide.png` - 통화별 우대와 한도 안내 삽입. 캡션: "모바일 환전 우대율과 한도 확인"]

신한은행의 모바일 안내는 휴대전화 본인인증이 가능한 만 14세 이상 개인의 24시간 신청과 지정 장소·날짜의 본인 수령을 설명해요. 신청이 24시간 가능하더라도 모든 수령점이 24시간 운영되는 것은 아닙니다.

| 확인 항목 | 살펴볼 점 |
| --- | --- |
| 💵 환율·우대 | 통화와 로그인 여부에 따라 달라질 수 있어 최종 거래 화면 확인 |
| 🏧 외화 ATM | 지점별 통화·운영시간과 선택 가능한 수령일 확인 |
| 🪪 수령 | 본인 신분증과 서비스별 필요 서류 확인 |

남은 외화를 다시 팔거나 외화예금에 넣을 때는 현찰수수료가 발생할 수 있어요. 수령일 변경이나 취소 가능 여부도 선택한 서비스의 현재 약관을 확인하세요.
