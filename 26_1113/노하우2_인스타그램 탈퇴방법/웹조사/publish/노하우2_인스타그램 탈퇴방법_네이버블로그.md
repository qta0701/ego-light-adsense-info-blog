사진을 남기고 싶다면 삭제 요청 전에 정보 사본부터 확인해 보세요.

영구 삭제하면 프로필과 사진, 동영상, 댓글, 좋아요, 팔로워가 삭제돼요. 필요한 자료가 있다면 로그인해 정보 사본을 먼저 내보내세요. 공식 도움말은 삭제 후 정보 내보내기 도구에 접근할 수 없다고 설명합니다.

| 확인 항목 | 살펴볼 내용 |
| --- | --- |
| 📁 사진·게시물 | 필요한 정보 사본을 삭제 전에 내보내기 |
| 👤 계정 선택 | 여러 프로필을 사용한다면 사용자 이름 재확인 |
| ⏸️ 잠시 쉬기 | 영구 삭제 대신 일시 비활성화도 검토 |

## 2. 계정 센터에 보이는 메뉴에 따라 선택

[이미지 배치 지시: `03_03_manage.png` - 계정 관리가 표시될 때 공식 절차 삽입. 캡션: "계정 관리가 표시되는 경우의 삭제 경로"]

[이미지 배치 지시: `04_04_account.png` - 계정이 표시될 때 공식 절차 삽입. 캡션: "계정이 표시되는 경우의 삭제 경로"]

공식 도움말은 계정 센터 하단에 표시되는 메뉴에 따라 두 경로를 안내해요. 컴퓨터에서 **더 보기 → 설정 → 계정 센터**로 들어간 뒤 보이는 메뉴를 살펴보세요.

| 표시되는 메뉴 | 이어지는 경로 |
| --- | --- |
| ⚙️ 계정 관리 | 프로필 및 개인정보 → 해당 계정 유형 옆 관리 → 비활성화 또는 삭제 |
| 👤 계정 | 개인정보 → 계정 소유권 및 관리 → 비활성화 또는 삭제 |

이후 삭제할 계정 또는 프로필을 선택하고 **계정 삭제 → 계속**을 누른 뒤 화면의 확인 절차를 따릅니다. 여러 계정을 관리한다면 마지막 선택 단계에서 사용자 이름을 다시 확인하세요.

## 3. 삭제 요청 뒤 기간과 로그인 문제

[이미지 배치 지시: `05_05_wait.png` - 삭제 후 기간과 지역별 차이 안내 삽입. 캡션: "삭제 요청 후 기간과 취소 가능 기간 확인"]

공식 안내에 따르면 삭제 요청 후 30일이 지나면 프로필과 정보를 가져올 수 없고, 전체 삭제 과정에는 최대 90일이 걸릴 수 있어요. 삭제 취소 가능 기간은 지역마다 다를 수 있으니 **실제 요청 화면의 기한**을 확인하세요.

| 상황 | 다음 확인 |
| --- | --- |
| 🔐 로그인 가능 | 계정 센터에서 본인이 삭제할 프로필 선택 |
| 🆘 로그인 불가 | 공식 고객센터의 로그인·계정 복구 절차부터 확인 |
| ⏳ 삭제 요청 후 | 화면에 표시된 취소 가능 기간과 상태 확인 |

이 조사는 공개 도움말을 확인한 것으로 계정에 로그인하거나 삭제를 요청하지 않았어요. 이미지는 실제 계정 설정 화면이 아닌 공식 절차 설명입니다.

## 4. 자주 묻는 질문

| **잠시 쉬고 싶은데 꼭 영구 삭제해야 하나요?** |
| --- |
| 일시 비활성화도 선택할 수 있습니다. 원하는 중단 방식에 맞는 공식 안내를 먼저 확인하세요. |

| **삭제 후 사진을 내려받을 수 있나요?** |
| --- |
| 공식 안내는 삭제 후 정보 내보내기 도구에 접근할 수 없다고 설명하므로 필요한 사본은 미리 보관하세요. |

| **삭제 취소 기한은 모두 같나요?** |
| --- |
| 지역별로 다를 수 있으므로 실제 요청 화면에 표시되는 기한을 확인해야 합니다. |
