# 코레일 민원접수 방법: 온라인 고객의 소리와 역 방문 안내

코레일 민원은 한국철도공사 홈페이지의 **고객의 소리**에서 신청할 수 있어요.

온라인 인증이 어렵다면 역 방문이나 서면 접수 안내도 함께 확인해 보세요.

## 1. 코레일 민원은 어디서 접수하나요?

[이미지 배치 지시: `01_search.png` - 한국철도 고객의 소리 검색 결과 삽입. 캡션: "한국철도 고객의 소리 공식 안내 찾기"]

한국철도공사 홈페이지에서 **고객참여 → 고객의소리 → 고객의소리 안내 및 신청**으로 이동해요. 이곳에서 신청과 처리 결과 확인에 관한 안내를 볼 수 있습니다.

| 접수 방법 | 시작할 곳 |
| --- | --- |
| 💻 온라인 | 고객의 소리 안내에서 VOC 바로가기 선택 |
| 🚉 역 방문 | 가까운 역에서 신청서와 동의서 작성 |
| ✉️ 서면 | 안내된 주소 또는 팩스로 발송 |

한국철도공사와 계열사의 소관이 아닌 내용은 해당 기관의 민원 사이트나 국민신문고를 이용하도록 안내하고 있어요. 접수 전에 담당 기관부터 확인하면 시간을 아낄 수 있습니다.

## 2. 온라인 신청과 본인확인 순서

[이미지 배치 지시: `02_guide.png` - 고객의 소리 바로가기 화면 삽입. 캡션: "고객의 소리 신청과 결과 확인 바로가기"]

[이미지 배치 지시: `04_guide.png` - 비회원 휴대폰 본인인증 버튼 삽입. 캡션: "비회원 휴대폰 본인인증 선택 화면"]

안내 페이지에서 **고객의 소리(VOC) 바로가기**를 누르면 로그인 화면으로 이동해요. 회원은 로그인하고, 비회원은 휴대폰 본인인증을 선택해 진행합니다. 인증이 어려우면 고객센터 1588-7788로 문의하도록 안내되어 있어요.

| 단계 | 확인할 내용 |
| --- | --- |
| ① 🔎 | 고객의 소리 안내 페이지에서 VOC 바로가기 선택 |
| ② 🔐 | 회원 로그인 또는 비회원 휴대폰 본인인증 |
| ③ 📝 | 인증 후 화면 안내에 따라 내용 작성·접수 |
| ④ 📬 | 고객의 소리 홈페이지에서 처리 결과 확인 |

이용 날짜, 열차나 역, 발생 상황과 원하는 답변을 미리 정리하면 내용을 구체적으로 전달하기 좋아요. 주민등록번호 등 불필요한 민감정보는 본문에 넣지 않도록 주의하세요.

인증 이후의 입력 항목과 처리 기간은 이번 조사에서 직접 확인하지 못했어요. 접수 화면에 표시되는 현재 안내를 확인해 주세요.

[이미지 배치 지시: `03_guide.png` - 역 방문 접수 안내 삽입. 캡션: "가까운 역에서 고객의 소리 신청하기"]

[이미지 배치 지시: `06_post_marked.png` - 서면 접수 주소와 팩스 안내 삽입. 캡션: "서면 민원 우편 주소와 팩스 안내"]

가까운 역에서는 개인정보 제공 동의서와 접점 VOC 신청서를 작성해 고객의 소리로 등록할 수 있어요. 회신은 문자, 이메일 또는 우편으로 받을 수 있습니다.

| 서면 접수 | 2026년 11월 13일 확인한 안내 |
| --- | --- |
| 📮 우편 | 우 34618, 대전광역시 동구 중앙로 240 한국철도공사 여객사업본부 여객서비스처 |
| 📠 팩스 | 02-361-8208 |
| 📩 회신 | 별도 회신 방법을 요청하지 않으면 우편 회신 안내 |

주소와 번호는 달라질 수 있으니 발송 직전에 공식 안내를 다시 확인하세요. 신청서를 보내기 전에 연락받을 방법도 살펴보면 좋습니다.
