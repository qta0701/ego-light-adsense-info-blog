먼저 바꾸려는 계정이 **미디어 및 구입 항목**에 쓰이는 계정인지 확인해 주세요. 이 경로는 기기 전체 Apple 계정 로그아웃과 구별해야 해요. Apple은 가족 공유 콘텐츠를 찾을 수 없을 때 이 메뉴의 계정을 확인하도록 안내합니다.

| 확인 항목 | 살펴볼 내용 |
| --- | --- |

| 👨‍👩‍👧 가족 공유 | 공유에 쓰는 계정과 구입 항목 공유 설정 확인 |

## 2. 아이폰·아이패드에서 로그아웃하기

[이미지 배치 지시: `02_guide.png` - Apple 지원 문서의 미디어 및 구입 항목 안내 삽입. 캡션: "아이폰에서 미디어 및 구입 항목을 선택하는 순서"]

설정 앱을 열고 맨 위의 사용자 이름을 누른 다음 **미디어 및 구입 항목 → 로그아웃 → 확인** 순서로 진행해요. 다른 계정이 필요하면 같은 메뉴를 다시 열어 화면에 나타나는 로그인 안내를 따라가면 됩니다.

| 순서 | 할 일 |
| --- | --- |
| ① ⚙️ | 설정을 열고 사용자 이름 선택 |
| ② 🛍️ | 미디어 및 구입 항목 선택 |
| ③ ✅ | 로그아웃을 누르고 확인 |
| ④ 🔑 | 필요하면 같은 메뉴에서 원하는 계정으로 다시 로그인 |

설정 화면 아래쪽의 기기 전체 로그아웃을 먼저 누르지 않도록 메뉴 이름을 한 번 더 확인하세요. Apple의 해당 안내에서는 iCloud나 iMessage 등 다른 서비스에서 로그아웃할 필요는 없다고 설명해요.

## 3. 맥과 가족 공유도 확인해요

[이미지 배치 지시: `04_guide.png` - Apple 지원 문서의 Mac 메뉴 안내 삽입. 캡션: "맥 App Store의 스토어 메뉴에서 로그아웃"]

[이미지 배치 지시: `05_family_marked.png` - Apple 지원 문서의 가족 공유 설정 안내 삽입. 캡션: "가족 공유와 구입 항목 계정 확인하기"]

맥에서는 **App Store를 열고 상단 메뉴 막대에서 스토어 → 로그아웃**을 선택해요. 다시 로그인할 때도 스토어 메뉴를 이용합니다. 아이폰의 설정 경로와 다르니 사용 중인 기기를 먼저 살펴보세요.

| 상황 | 확인하면 좋은 점 |
| --- | --- |
| 🔄 다른 계정으로 전환 | 기존 구입 항목에 사용한 계정을 미리 확인 |
| 👪 공유 콘텐츠가 안 보임 | 가족 공유와 미디어 및 구입 항목의 계정, 구입 항목 공유 설정 확인 |
| 🔐 암호·인증 요청 | 본인 기기에서 표시되는 안내를 직접 확인 |

가족이 공유하는 콘텐츠가 보이지 않는다면 계정만 바꾸기 전에 공유 가능한 콘텐츠인지와 숨긴 구입 항목도 확인해 보세요. 계정이나 인증 정보를 다른 사람에게 전달하지 않고 본인 기기에서 진행하는 것이 좋아요.

## 4. 자주 묻는 질문

| **아이폰에서 로그아웃 메뉴가 어디에 있나요?** |
| --- |
| 설정에서 사용자 이름을 누르고 미디어 및 구입 항목을 선택한 뒤 로그아웃과 확인을 차례로 누릅니다. |

| **미디어 및 구입 항목에서 로그아웃하면 iCloud도 나가야 하나요?** |
| --- |
| Apple의 가족 공유 안내는 이 절차를 위해 iCloud나 iMessage 등 다른 서비스에서 로그아웃할 필요가 없다고 설명합니다. |

| **맥에서도 같은 설정 경로를 사용하나요?** |
| --- |
| 맥에서는 App Store를 열고 상단 메뉴 막대의 스토어에서 로그아웃을 선택합니다. |
