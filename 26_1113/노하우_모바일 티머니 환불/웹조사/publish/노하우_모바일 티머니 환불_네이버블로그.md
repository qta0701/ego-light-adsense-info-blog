# 모바일 티머니 환불: 선불 잔액 신청 방법과 USIM 확인

모바일 티머니 선불 잔액은 앱의 **교통카드 → 환불신청**에서 신청할 수 있어요.

기기와 카드 유형에 따라 조건이 다를 수 있으니 신청 화면을 먼저 확인해 주세요.

| 💳 모바일 티머니 환불 경로 자세히 보기 |
| --- |

https://how.supportimes.com/2026/11/usim.html

## 1. 환불 전 카드 유형을 확인하세요

[이미지 배치 지시: `01_01_search.png` - 티머니 공식 USIM 교체 FAQ 검색 결과 삽입. 캡션: "티머니 공식 모바일티머니 FAQ 확인"]

충전한 잔액을 사용하는 선불충전형과 나중에 청구되는 후불청구형은 확인할 절차가 달라요. 아래 Android 안내는 **LG유플러스 USIM 교체 관련 공식 FAQ**를 2026년 11월 13일 확인한 내용입니다. 이 FAQ는 iPhone 이용자에게 적용되지 않는다고 밝혀요.

| 이용 형태 | 먼저 확인할 점 |
| --- | --- |
| 🤖 Android 선불충전형 | 앱의 환불신청과 기존 USIM 보관 여부 |
| 💳 Android 후불청구형 | 잔액 환불과 별도로 서비스 해지 안내 확인 |
| 🍎 iPhone | 아이폰용 모바일티머니 안내와 현재 앱 화면 확인 |

금액, 수수료와 입금 일정은 실제 신청 화면이나 고객센터에서 확인하세요. 아래 이미지는 공식 설명 및 예시 화면으로, 직접 환불을 신청한 화면은 아닙니다.

| 🔎 환불 전 확인사항 살펴보기 |

## 2. 선불 잔액 환불 신청하기

[이미지 배치 지시: `02_02_refund.png` - Android 선불충전형 환불 경로 안내 삽입. 캡션: "Android 선불충전형 환불 신청 경로"]

[이미지 배치 지시: `05_iphone_refund_marked.png` - 아이폰용 티머니 공식 환불 예시 화면 삽입. 캡션: "아이폰용 모바일티머니 환불 계좌 입력 예시"]

Android의 해당 FAQ에서는 앱 왼쪽 위 **전체메뉴 → 교통카드 → 환불신청**으로 이동해 등록 계좌를 선택하거나 새 계좌를 입력하도록 안내해요. 유의사항을 읽고 확인란을 체크한 뒤 환불하기를 선택합니다.

| 순서 | 확인할 내용 |
| --- | --- |
| ① ☰ | 앱 전체메뉴에서 교통카드 → 환불신청 선택 |
| ② 🏦 | 환불받을 계좌를 선택하거나 입력 |
| ③ ✅ | 유의사항·환불액·계좌를 확인한 뒤 신청 |

티머니의 아이폰용 공식 안내도 앱에서 환불 계좌를 입력하는 예시를 보여줘요. 이미지의 금액과 수수료는 **예시**이므로 내 계정의 실제 금액으로 생각하지 말고 신청 화면에서 다시 확인하세요.

## 3. USIM 교체와 후불형은 따로 살펴보세요

[이미지 배치 지시: `04_04_usim.png` - 기존 USIM 보관 안내 삽입. 캡션: "Android 잔액 환불 전 기존 USIM 확인"]

[이미지 배치 지시: `03_03_postpaid.png` - 후불청구형 해지 경로 안내 삽입. 캡션: "USIM 교체 전 후불청구형 해지 안내"]

해당 Android FAQ에 따르면 선불 잔액은 USIM에 저장되며 환불에는 충전한 이전 USIM 실물이 필요해요. 교체 전에 잔액과 신청 상태를 확인하고 기존 USIM을 보관하세요.

| 상황 | FAQ에서 안내하는 확인 |
| --- | --- |
| 📱 후불청구형 | 교체 전 전체메뉴 → 교통카드 → 충전형 서비스 전환 → 전환신청 → 확인 |
| ⏳ 최초 승인 금액 | 4~5영업일 이내 자동 취소 안내, 카드사별 시간 차이 가능 |
| ☎️ 해지 없이 USIM 교체 | 티머니 고객센터 1644-0088 문의 |

이 안내는 해당 FAQ의 적용 범위 안에서 확인하세요. 모바일기후동행카드·페이머니·페이교통카드는 교체 전 환불 신청이 필요하지 않다고 별도로 안내합니다.
