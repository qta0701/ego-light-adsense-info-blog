# 국민은행 통장사본 출력: PC 메뉴와 제출 전 확인사항

국민은행 통장사본은 PC 개인뱅킹의 **뱅킹관리 → 제증명발급 → 통장사본**에서 찾을 수 있어요.

출력하기 전 제출처가 원하는 계좌와 파일 형식도 확인해 보세요.

| 🏦 통장사본 출력 경로 자세히 보기 |
| --- |

https://bank.supportimes.com/2026/11/pc-stm.html

국민은행 개인뱅킹에서 **뱅킹관리**를 선택하고 제증명발급 영역의 **통장사본**을 누르면 로그인 화면으로 연결돼요. 공식 메뉴와 로그인 전 화면은 2026년 11월 13일 확인했습니다.

| 단계 | 확인할 내용 |
| --- | --- |
| ① 🏦 | 공식 개인뱅킹의 뱅킹관리 메뉴 선택 |
| ② 📄 | 제증명발급에서 통장사본 선택 |
| ③ 🔐 | 본인이 사용하는 방식으로 로그인 |

개인 계정에 로그인하지 않아 이후 계좌 목록과 실제 인쇄 화면은 직접 확인하지 못했어요. 버튼 이름이 다르면 현재 화면을 기준으로 확인해 주세요.

## 2. 로그인 후 계좌와 형식을 확인해요

[이미지 배치 지시: `03_guide.png` - 통장사본 로그인 선택 화면 삽입. 캡션: "국민은행 개인뱅킹 로그인 방식 선택"]

별도 사용 안내에 따르면 로그인 후 필요한 계좌의 한글 또는 영문 미리보기를 선택해 인쇄할 수 있어요. 이 단계는 공개된 제3자 설명을 참고한 것으로, 현재 로그인 후 화면은 직접 검증하지 못했습니다.

| 선택할 것 | 살펴볼 내용 |
| --- | --- |
| 👤 계좌 | 제출할 예금주와 계좌번호가 맞는지 확인 |
| 🌐 언어 | 제출처가 한글 또는 영문을 요구하는지 확인 |
| 🖨️ 인쇄 | 프린터를 선택하거나 인쇄창에 PDF 저장이 있으면 해당 형식 확인 |

통장사본과 계좌개설확인서는 제출처가 원하는 서류가 다를 수 있어요. 저장하거나 인쇄하기 전에 어떤 서류와 형식이 필요한지 먼저 물어보면 재출력을 줄일 수 있습니다.

## 3. 스마트폰과 STM 이용 시 확인

[이미지 배치 지시: `04_guide.png` - 국민은행 STM 가능 업무 안내 삽입. 캡션: "국민은행 STM의 통장 사본 출력 안내"]

별도 사용 안내는 KB스타뱅킹 로그인 후 계좌의 더보기에서 통장사본을 선택해 저장하는 경로를 설명해요. 앱 내부를 직접 확인하지 못했으므로 실제 메뉴와 계좌 종류에 맞는 안내를 확인하세요.

| 방법 | 확인할 점 |
| --- | --- |
| 📱 스마트폰 | 현재 앱에서 통장사본 메뉴와 인증 안내 확인 |
| 🏧 STM | 일반 ATM과 구분하고 운영점·인증 가능 시간 확인 |
| 🔒 제출 | 저장된 파일에 예금주와 계좌정보가 포함되므로 필요한 곳에만 전달 |

국민은행 STM 안내에는 통장 사본 출력이 가능 업무로 포함돼 있어요. 이용대상과 제외 조건이 있으니 방문 전에 공식 운영점 안내를 확인하세요.
