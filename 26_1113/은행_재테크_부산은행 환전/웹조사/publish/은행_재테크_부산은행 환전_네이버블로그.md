# 부산은행 환전: ONE환전 신청 전 수령 방법과 한도 확인

부산은행 ONE환전은 외화를 신청한 뒤 **수령·현찰배달·금고보관** 중 가능한 방식을 선택하는 서비스예요.

로그인 여부에 따라 이용 조건이 달라서 신청 전 한도와 수령 방법을 확인해 주세요.

| --- |

https://bank.supportimes.com/2026/11/one.html

## 1. ONE환전 이용 대상과 시간

[이미지 배치 지시: `02_guide.png` - 부산은행 ONE환전 서비스 개요 삽입. 캡션: "부산은행 ONE환전 서비스 안내"]

[이미지 배치 지시: `03_guide.png` - 이용 대상과 시간 안내 삽입. 캡션: "ONE환전 이용 대상과 시간 확인"]

부산은행 공식 홈페이지의 **금융상품 → 외환 → 환전 → 환전서비스안내 → ONE환전**에서 안내를 볼 수 있어요. 2026년 11월 13일 확인한 개인 이용 대상은 국민인 거주자 개인입니다.

| 항목 | 공식 안내에서 확인한 내용 |
| --- | --- |
| 🕒 이용시간 | 24시간·365일. 금고보관은 주말·공휴일 거래 불가 |
| 🏦 비로그인 입금 | 가상계좌 입금은 23:30~24:30 불가 |
| 💵 통화 | USD·JPY·EUR·CNY 등을 포함한 15개 통화 안내 |

환전 가능한 통화가 모든 지점에 준비되어 있다는 뜻은 아니에요. 필요한 통화와 권종을 수령할 지점이 보유하는지 미리 확인하세요.

## 2. 로그인 여부와 수령 방법 비교

[이미지 배치 지시: `04_guide.png` - 로그인별 환전 한도 안내 삽입. 캡션: "ONE환전 로그인별 신청 한도"]

[이미지 배치 지시: `05_guide.png` - 수령 방법 비교표 삽입. 캡션: "환전수령·현찰배달·금고보관 비교"]

로그인 환전은 미화 100달러부터 1만 달러 이하로 안내하며 부산은행 비대면 환전 신청액과 미수령 잔액을 합산해요. 비로그인 환전은 원화 100만원 이하입니다. 실제 거래에 적용되는 범위는 신청 화면에서 다시 확인하세요.

| 방식 | 확인할 점 |
| --- | --- |
| 👤 로그인 | 환전수령은 본인·대리인 가능. 대리 서류는 지점에 문의 |
| 🚶 비로그인 | 환전수령은 본인만 가능. 현찰배달·금고보관 불가 안내 |
| 🏢 영업점 | 신청 시점에 해당 외화를 보유한 영업점에서 수령 |

신청 과정의 세부 입력 화면은 직접 확인하지 않았어요. 거래를 확정하기 전 은행 화면의 통화·금액·수령일과 적용환율을 확인해 주세요.

## 3. 수령일과 배송 조건도 확인해요

[이미지 배치 지시: `06_delivery_marked.png` - 현찰배달 수수료 안내 삽입. 캡션: "ONE환전 현찰배달 조건과 배송비 안내"]

영업점 수령은 신청일로부터 30일 이내 인수와 인수예정일을 포함한 7영업일의 유효기간이 안내돼 있어요. 실제 신청 내역에 표시된 날짜를 꼭 확인하세요.

| 수령 관련 | 주의할 내용 |
| --- | --- |
| 📦 현찰배달 | 로그인 고객 대상, 안내된 금액·통화 조건과 배송비 확인 |
| 🏧 외화 ATM | 당일 인수 불가, 지점별 취급 통화 확인 |
| ⏳ 유효기간 경과 | 로그인은 금고 자동 보관, 비로그인은 조건에 따라 자동환매 가능 |

현찰배달 안내에는 미화 100달러 이상이면서 원화 150만원 이하, 건당 배송비 1만원 등 조건이 표시돼요. 자동환매 때는 환율에 따라 원화 금액이 달라질 수 있으니 신청 직전 최신 안내를 살펴보세요.

## 4. 자주 묻는 질문

| **비로그인으로도 현찰배달을 신청할 수 있나요?** |
| --- |
| 확인한 비교표는 비로그인 고객의 현찰배달과 금고보관을 이용 불가로 안내합니다. |

| **대리인이 외화를 받을 수 있나요?** |
| --- |
| 로그인 고객의 환전수령은 본인과 대리인 수령이 가능하다고 안내합니다. 필요 서류는 방문 전 지점에 문의하세요. |

| **환전한 돈을 늦게 찾으면 어떻게 되나요?** |
| --- |
| 유효기간 경과 후 로그인·비로그인에 따라 금고 보관 또는 자동환매가 적용될 수 있습니다. 신청 내역과 최신 안내를 확인하세요. |
