# 테무 회원탈퇴 방법: 앱과 웹 계정 삭제 및 취소 안내

테무 회원탈퇴는 로그인한 뒤 **계정 보안 → Temu 계정 삭제**에서 요청할 수 있어요.

앱과 웹의 진입 위치가 다르니 사용 중인 화면에 맞춰 확인해 보세요.

## 1. 탈퇴 전에 확인할 것

[이미지 배치 지시: `01_search.png` - Temu 계정 삭제 공식 도움말 검색 결과 삽입. 캡션: "Temu 공식 고객센터의 계정 삭제 안내"]

계정 삭제를 요청하기 전에는 진행 중인 주문이나 반품·환불, 보관할 거래 기록을 확인해 두는 것이 좋아요. 나중에 삭제 요청을 취소할 가능성도 생각해 로그인 수단을 기억해 두세요.

| 확인 항목 | 살펴볼 내용 |
| --- | --- |
| 📦 주문 | 배송 중인 주문이 있는지 확인 |
| 💳 반품·환불 | 진행 중인 처리가 있는지 확인 |
| 🧾 기록 | 필요한 거래 내역을 미리 살펴보기 |

이 항목들은 준비를 돕는 확인 사항이에요. 삭제가 주문이나 환불에 미치는 결과를 보장하는 뜻은 아니므로 관련 상황은 현재 고객센터 안내를 확인하세요.

## 2. 앱과 웹에서 삭제 메뉴 찾기

[이미지 배치 지시: `02_guide.png` - Temu 앱 삭제 경로 공식 안내 삽입. 캡션: "Temu 앱의 설정과 계정 보안 경로"]

[이미지 배치 지시: `03_guide.png` - Temu 웹 삭제 경로 공식 안내 삽입. 캡션: "Temu 웹사이트의 계정 보안 경로"]

앱에서는 로그인 후 화면 하단의 사용자 아바타를 누르고 **설정 → 계정 보안 → Temu 계정 삭제**를 선택해요. 웹에서는 로그인 후 오른쪽 위 사용자 아바타에서 **계정 보안 → Temu 계정 삭제**로 이동합니다.

| 구분 | 첫 진입 | 이어서 선택 |
| --- | --- | --- |
| 📱 앱 | 하단 사용자 아바타 | 설정 → 계정 보안 → 계정 삭제 |
| 💻 웹 | 오른쪽 위 사용자 아바타 | 계정 보안 → 계정 삭제 |

앱과 웹의 첫 위치를 혼동하지 않도록 사용 중인 환경부터 확인하세요. 이미지는 2026년 11월 13일 확인한 공식 도움말 발췌이며 실제 로그인 후 화면은 아닙니다. 마지막 확인 화면에서는 표시되는 내용을 직접 읽고 진행해 주세요.

## 3. 삭제 요청 후 취소할 수 있나요?

[이미지 배치 지시: `04_guide.png` - 계정 삭제 처리와 취소 기한 공식 안내 삽입. 캡션: "Temu 계정 삭제 처리와 취소 안내"]

Temu 공식 안내는 영구 삭제를 요청하면 자동 로그아웃되고, 계정은 **7영업일 이내** 영구 삭제된다고 설명해요. 계정을 유지하려면 기한 전에 다시 로그인해 삭제 절차를 취소할 수 있다고 안내합니다.

| 시점 | 확인할 점 |
| --- | --- |
| ⏳ 요청 직후 | 자동 로그아웃과 처리 상태 확인 |
| 🔄 기한 전 | 계정을 유지하려면 로그인 후 취소 안내 확인 |
| ✅ 처리 후 | 요청과 완료는 다르므로 표시되는 상태 확인 |

삭제를 실제로 요청하지 않았기 때문에 로그인 이후 확인 화면은 검증하지 못했어요. 처리 기간이나 메뉴는 바뀔 수 있으므로 요청 시점의 공식 안내를 다시 살펴보세요.

## 4. 자주 묻는 질문

| **앱에서 계정 삭제는 어디에 있나요?** |
| --- |
| 로그인 후 하단 사용자 아바타에서 설정, 계정 보안 순서로 이동해 Temu 계정 삭제를 선택합니다. |

| **삭제 요청을 하면 바로 영구 삭제되나요?** |
| --- |
| 확인한 공식 안내는 자동 로그아웃 후 7영업일 이내에 영구 삭제된다고 설명합니다. |

| **삭제 요청을 취소할 수 있나요?** |
| --- |
| 공식 안내에 따르면 기한 전에 다시 로그인해 삭제 절차를 취소할 수 있습니다. 현재 화면의 안내도 확인해 주세요. |
