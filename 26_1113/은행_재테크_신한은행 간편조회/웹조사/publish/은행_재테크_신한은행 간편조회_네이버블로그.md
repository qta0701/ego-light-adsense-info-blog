## 2. 계좌조회는 로그인 수단을 선택해요

[이미지 배치 지시: `02_guide.png` - 계좌조회 로그인 진입 화면 삽입. 캡션: "간편조회 계좌조회 로그인 수단"]

공식 간편조회 화면에서 **계좌조회**를 선택하면 확인 당시 인증서와 이용자 ID 로그인 영역이 나타났어요. 본인에게 해당하는 방법을 선택해 은행 화면에서 직접 로그인하세요.

| 순서 | 할 일 |
| --- | --- |
| ① 🌐 | 신한은행 공식 간편조회서비스 접속 |
| ② 🏦 | 계좌조회 선택 |
| ③ 🔑 | 금융·공동인증서 또는 이용자 ID 방식 확인 |

아이디나 인증서 비밀번호를 다른 사람에게 전달하지 말고 본인 기기에서 직접 입력하세요. 로그인 후 계좌와 거래내역은 조사에서 열지 않았으므로 이후 메뉴 구성은 실제 화면을 기준으로 확인해 주세요.

## 3. 기타조회와 로그인 문제 확인

[이미지 배치 지시: `04_guide.png` - 기타조회 메뉴 화면 삽입. 캡션: "기타조회 메뉴에서 환율 등 항목 찾기"]

상단 **기타조회**를 펼치면 환율조회 등 별도 항목으로 이동할 수 있어요. 로그인 없이 이용 가능한 항목이라도 각 서비스가 요구하는 조회 정보와 조건은 해당 화면에서 확인해야 합니다.

| 상황 | 확인할 곳 |
| --- | --- |
| 🔍 아이디를 잊음 | 로그인 영역의 아이디 찾기 안내 |
| 🔐 인증서 관리 | 은행 홈페이지 또는 안내된 앱의 인증센터 |
| 📱 모바일 이용 | 이번 이미지는 PC 화면이므로 앱의 현재 메뉴 확인 |

아이핀 회원은 개인회원으로 전환한 뒤 계좌조회를 이용할 수 있다는 안내도 표시돼요. 거래내역을 공유하기 전에는 계좌번호나 잔액 등 개인정보가 포함되어 있는지 살펴보세요.

## 4. 자주 묻는 질문

| **간편조회면 계좌 잔액을 로그인 없이 볼 수 있나요?** |
| --- |
| 확인한 계좌조회 진입 화면에는 인증서와 이용자 ID 로그인 수단이 표시됐습니다. 본인의 이용 유형과 현재 은행 안내를 확인하세요. |

| **환율조회는 어디에 있나요?** |
| --- |
| 간편조회 주요서비스 또는 상단 기타조회 메뉴에서 환율조회 항목을 찾을 수 있습니다. |

| **앱에서도 화면이 똑같나요?** |
| --- |
| 여기서 확인한 것은 PC 웹 화면입니다. 앱 메뉴와 로그인 방식은 다를 수 있습니다. |
