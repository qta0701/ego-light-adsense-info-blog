# 국민은행 환전신청 방법: 지점 수령 전 한도와 날짜 확인

국민은행 환전신청은 개인뱅킹의 **외환 → 환전 → 환전신청**에서 시작할 수 있어요.

지점에서 받을 계획이라면 통화와 수령일, 결제 방식을 먼저 확인해 보세요.

국민은행 환전신청 화면에는 지점에서 받기, 외화배달, 외화 선물하기가 표시돼요. 여기서는 **지점에서 받기**를 기준으로 설명합니다. 신청하기 전에 이용안내에서 대상과 통화, 한도와 수령일을 읽어 주세요.

| 확인 항목 | 살펴볼 내용 |
| --- | --- |
| 👤 대상 | 지점 수령과 비로그인 서비스의 이용 대상 확인 |
| 💵 통화 | 수령할 외화와 지점의 보유 여부 확인 |
| 📅 날짜 | 통화별 수령 가능일과 지점 영업시간 확인 |

## 2. 로그인 또는 비로그인으로 신청

[이미지 배치 지시: `03_guide.png` - 로그인·비로그인 선택 화면 삽입. 캡션: "환전신청 로그인 방식 선택"]

[이미지 배치 지시: `04_guide.png` - 비로그인 약관 확인 화면 삽입. 캡션: "비로그인 환전의 약관 확인 단계"]

[이미지 배치 지시: `05_guide.png` - 로그인별 결제 방식 안내 삽입. 캡션: "로그인 여부에 따른 환전 결제 방식"]

신청하기를 누르면 로그인 또는 비로그인 환전신청을 선택할 수 있어요. 비로그인 경로는 약관동의 → 정보입력 → 입력정보확인 순서로 표시됐습니다. 약관은 직접 읽고 실제 화면의 안내에 따라 진행하세요.

| 방식 | 2026년 11월 13일 확인한 결제 안내 |
| --- | --- |
| 🔐 인증서 로그인 | 본인 명의 계좌에서 출금 |
| 📱 인증서 비로그인 | 신청 완료 후 30분 이내 가상계좌 입금 |
| 💳 입금 전 | 송금 은행의 입금 수수료 발생 가능성 확인 |

비로그인은 국민인 거주자 개인을 대상으로 원화 100만원 상당액 이하, 최소 미화 50달러 상당액 이상으로 안내됩니다. 로그인 한도는 시간과 다른 비대면 거래·미수령 금액에 따라 달라지므로 현재 이용안내를 확인하세요.

## 3. 수령일과 취소 조건 살펴보기

[이미지 배치 지시: `06_guide.png` - 통화별 수령일 안내 삽입. 캡션: "지점 수령 통화별 수령희망일"]

[이미지 배치 지시: `07_guide.png` - 완료 후 취소와 되팔기 안내 삽입. 캡션: "환전 완료 후 취소·되팔기 유의사항"]

일반 영업점의 USD·JPY·EUR·CNY와 기타 통화는 수령일 선택 범위가 다르게 안내돼요. 지점 재고와 영업시간도 영향을 주므로 방문 전 지점과 신청 내역을 함께 확인하세요.

| 항목 | 확인할 내용 |
| --- | --- |
| 🪪 성인 본인 수령 | 신청번호가 포함된 문자와 본인 신분증 준비 |
| 📆 기타 통화 | 안내상 신청일부터 2영업일 이후부터 수령일 선택 |
| 🔁 완료 후 | 취소할 수 없으며 되팔기 시 환율 차이가 생길 수 있음 |

수령희망일 포함 7영업일까지 찾지 않으면 8영업일 자동 되팔기가 적용되는 경우와 예외가 안내돼 있어요. 실제 신청 내역의 기한을 놓치지 않도록 확인해 주세요. 개인정보 입력과 실제 환전 거래는 이번 조사에서 진행하지 않았습니다.

## 4. 자주 묻는 질문

| **비로그인으로 신청한 돈은 언제 입금하나요?** |
| --- |
| 확인한 지점 수령 안내는 신청 완료 후 30분 이내 가상계좌 입금을 안내합니다. 실제 화면의 기한을 확인하세요. |

| **환전한 외화를 어느 지점에서나 받을 수 있나요?** |
| --- |
| 지점별 외화 재고와 영업시간이 다를 수 있어 수령 희망 지점에 미리 확인하는 것이 좋습니다. |

| **환전 완료 후 취소할 수 있나요?** |
| --- |
| 공식 안내는 완료된 환전은 취소할 수 없으며 되팔기 시 환율 차이가 생길 수 있다고 설명합니다. |
