통합회원을 고르면 공식 가이드는 이용약관과 개인정보 수집·이용 동의 단계를 안내해요. 실제 가입 화면에서 필수와 선택 항목을 각각 읽고 필요한 동의를 선택하세요.

| 단계 | 확인할 내용 |
| --- | --- |
| ① 📝 | 약관과 개인정보 동의 항목 확인 |
| ② 🆔 | 아이디 중복 확인과 비밀번호 입력 |
| ③ 📱 | 지원자 본인의 이름·생년월일·연락처 등 입력 |

연락처는 계정 찾기나 대학의 문자 수신 등에 쓰일 수 있어 본인이 확인할 수 있는 번호를 입력하는 것이 좋아요. 위 그림은 공식 초보자 가이드의 예시이며 현재 양식과 다를 수 있습니다. 입력 조건은 실제 화면을 우선해 주세요.

## 3. 가입과 원서 제출은 별도예요

회원가입을 마친 뒤 로그인해 본인 정보와 공통원서 작성 메뉴를 확인해 보세요. **회원가입만으로 대학 원서 제출이 완료되는 것은 아닙니다.** 대학 선택, 원서 작성, 결제와 접수 확인은 해당 모집요강과 사이트 안내에 따라 별도로 진행해요.

| 상황 | 다음 확인 |
| --- | --- |
| 🔄 이미 단일회원 | 새 계정 생성 전 기존 계정과 통합회원 전환 안내 확인 |
| 📞 가입이 막힘 | 화면의 오류 안내 확인 후 고객센터 1544-7715 문의 |
| 🎫 원서 제출 전 | 지원 대학의 접수처·모집요강·제출 상태 확인 |

이번 조사에서는 개인정보 입력, 본인인증과 가입 제출을 진행하지 않았어요. 최종 제출 전에는 표시된 정보를 한 번 더 확인하세요.

| **휴대폰에서 원서를 작성할 수 있나요?** |

| **회원가입을 하면 대학 원서도 접수되나요?** |
| --- |
| 아닙니다. 대학 선택과 원서 작성, 결제 및 접수 확인은 별도로 진행해야 합니다. |
