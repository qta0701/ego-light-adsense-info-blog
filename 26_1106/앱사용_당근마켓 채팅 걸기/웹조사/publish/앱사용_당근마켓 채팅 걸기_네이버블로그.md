## 1. 중고거래 게시글에서 판매자에게 채팅 시작하기

[이미지 배치 지시: `02_guide.png` - 당근마켓 공식 중고거래 상세 화면 하단 [채팅하기] 버튼 위치 안내 예시 화면 삽입. 캡션: "당근 공식 도움말 중고거래 게시글 하단 채팅하기 버튼 위치"]

구매를 원하는 중고 물품을 발견했다면 검색 목록에서 사진만 보지 마시고 해당 게시글을 터치해 상세 화면으로 먼저 들어가야 해요.

상세 화면 맨 아래를 보시면 주황색 바탕의 [채팅하기] 버튼이 자리 잡고 있어서 터치 한 번으로 판매자와 1:1 대화방이 즉시 개설돼요.

이때 판매자의 프로필만 보고서는 바로 대화를 걸 수 없으며, 반드시 판매 중인 개별 게시글을 통해서만 채팅을 시작할 수 있다는 점을 꼭 기억해 두셔야 해요.

- ⏰ **거래 가능 시간 제시**: 단순 구매 문의보다 직거래를 희망하는 시간대나 장소를 함께 남기면 답장이 훨씬 빨라져요.

## 2. '대화중인 채팅' 문구 변경과 동네생활 대화 조건

[이미지 배치 지시: `03_guide.png` - 기존 대화가 있을 때 [대화중인 채팅]으로 변경되는 안내와 바로구매 게시글 예외 화면 삽입. 캡션: "기존 대화방 개설 시 변경되는 버튼 문구 예시"]

이전에 대화를 한 번이라도 나누었던 판매글로 다시 들어가면 하단 버튼 이름이 [채팅하기]가 아니라 [대화중인 채팅]으로 바뀌어 있어요.

이는 앱 오류나 시스템 장애가 아니라 이미 개설된 1:1 대화방이 존재한다는 뜻이므로, 버튼을 누르면 기존 대화 내역으로 바로 연결돼요.

다만 바로구매가 적용된 게시글은 대화 이력이 있더라도 [채팅하기] 문구가 그대로 유지될 수 있으니 혼동하지 않으셔도 돼요.

| **게시글 유형별 하단 버튼 표기 비교** 🔍 |
| :--- |

| 게시글 구분 📱 | 이전 대화 없음 🆕 | 이전 대화 존재 🔄 | 특징 및 확인 사항 💡 |
| :--- | :--- | :--- | :--- |
| 📦 일반 중고거래 | [채팅하기] 표시 | [대화중인 채팅]으로 자동 변경 | 기존 대화방 기록으로 즉시 이동하여 대화 지속 |
| ⚡ 바로구매 진행 매물 | [채팅하기] 표시 | [채팅하기] 문구 그대로 유지 | 바로구매 옵션이 활성화된 게시글의 고유 표시 형태 |
| 🏡 동네생활 소통 글 | 하단 버튼 없음 | 하단 버튼 없음 | 댓글 작성자 오른쪽 더보기(⋮) 메뉴를 통해서만 개설 |

동네생활 게시판에서는 중고거래와 완전히 다른 규칙이 적용되는데요, 글을 읽는 모든 이웃이 개인 채팅을 시작할 수 있는 것이 아니에요.

오직 해당 글을 올린 '게시글 작성자'만이 본인 글에 달린 댓글 오른쪽의 더보기(⋮) 아이콘을 눌러 [채팅하기]를 선택할 수 있답니다.

따라서 동네생활에서 개인 대화를 나누고 싶다면 댓글을 먼저 남겨 글 작성자가 말을 걸어오도록 유도하시는 것이 올바른 방법이에요.

## 3. 직접 PC 웹과 앱에서 당근채팅을 연결해보며 느낀 점

[이미지 배치 지시: `05_guide.png` - 당근 웹채팅 PC 로그인 QR 인증 화면 및 연결 방식 안내 삽입. 캡션: "당근 공식 웹채팅 PC 로그인 및 QR 스캔 안내 화면"]

제가 직접 스마트폰을 두고 컴퓨터로 작업하던 중 당근 웹채팅에 접속해 로그인을 시도해 보았는데요, 아이디와 비밀번호를 치는 방식이 아니라 화면에 뜬 QR 코드를 스마트폰으로 스캔해야 해서 처음엔 살짝 헷갈리더라구요. 당근 앱의 [나의 당근] 메뉴에서 우측 상단 설정 아이콘을 누른 뒤 [QR 코드 스캔]으로 카메라를 비추니 1초 만에 PC 화면에 대화창이 열렸어요.

실제 PC 화면에서 거래 메시지를 주고받아보니 긴 주소나 계좌 정보를 복사해 붙여넣거나 키보드로 타자를 칠 때 모바일보다 훨씬 수월하고 오타 걱정도 줄어들더라구요. 다만 공식 누리집과 고객센터 문서를 꼼꼼히 대조해보니 PC 웹 버전에서는 새 판매글 검색이나 첫 대화 개설은 지원하지 않고 기존에 열려 있는 대화방만 이어갈 수 있다는 제한이 있더라구요.

그래서 저는 밖에서 물건을 검색할 때는 모바일 앱에서 미리 [채팅하기]를 눌러 대화방을 먼저 만들어 두고, 집에 돌아와 약속 장소 조율이나 상세 문의를 할 때는 PC 웹을 활용하는 방식을 쓰고 있어요. 이렇게 두 가지 환경을 적절히 나누어 사용하시면 중고거래 소통이 한결 쾌적해지실 거예요.

## 4. 자주 묻는 질문 (FAQ) ❓

| **Q1. 판매자의 닉네임이나 프로필만 알고 있을 때도 먼저 채팅을 걸 수 있나요?** |
| :--- |
| A1: 아니요, 당근마켓은 개인 프로필만 보고 임의로 1:1 대화를 거는 기능을 지원하지 않아요. 반드시 판매자가 등록한 개별 중고거래 게시글 상세 화면으로 들어가서 하단의 [채팅하기] 버튼을 눌러야 대화방이 정상적으로 개설돼요. |

| **Q2. 게시글 상세 화면에 들어갔는데 [채팅하기] 버튼이 보이지 않는 이유는 무엇인가요?** |
| :--- |
| A2: 본인이 작성한 판매 게시글이거나 거래가 이미 완료되어 숨김 처리된 경우에는 채팅 버튼이 나타나지 않아요. 또한 동네생활 게시판의 글은 하단 버튼 대신 댓글 오른쪽 더보기 메뉴를 통해서만 글 작성자에게 채팅 권한이 주어진답니다. |

| **Q3. PC 웹 브라우저에서 당근채팅을 이용할 때 별도의 프로그램 설치가 필요한가요?** |
| :--- |
| A3: 별도의 설치 프로그램 없이 크롬이나 웨일 등 웹 브라우저에서 공식 웹채팅 주소로 접속하시면 바로 이용하실 수 있어요. 스마트폰 당근 앱의 QR 코드 스캔 메뉴를 통해 간편하게 인증하시면 열려 있는 채팅방을 그대로 이용하실 수 있어요. |
