# 코레일 분실물 센터 웹조사 결과

- 조사일: **2026-11-06 (한국 시간)**
- 대상: `1.애드센스_콘텐츠표` → `앱사용` → **47행 / I47**
- 수집 도구: ego-browser, Google 검색 후 코레일·경찰민원24 공식 웹 확인
- 결과물: 조사 문서, 안내 이미지 14장, 대응 원본 14장, 출처·검색 검증 JSON
- 범위: 코레일 모바일 웹과 경찰민원24 공개 조회·신고 안내를 확인했다. 신고는 로그인 필요 안내에서 중단했다.

## 1. 검색 의도

Google에서 **코레일 분실물 센터**를 먼저 검색했다. 광고를 제외한 상위 결과에는 코레일의 유실물신고안내와 유실물 찾기가 먼저 나타났고, LOST112 기존 모바일 주소와 역별 수령 후기도 노출됐다. 검색자는 급하게 연락할 전화번호, 어느 역에 물건이 있는지 확인하는 방법, 온라인 조회·신고, 수령 준비물과 보관 기간을 원한다고 해석했다.

Google AI 개요나 블로그의 옛 전화번호를 최종 근거로 쓰지 않고, 공식 페이지에서 연락처와 연결 사이트를 다시 확인했다. `검색결과_참고기록.json`과 00번 캡처는 순위의 영구 증거가 아닌 조사 당시의 참고 기록이다.

## 2. 먼저 해야 할 일

**공식 안내:** [코레일 유실물신고안내](https://www.korail.com/ticket/guest/lost/register)

| 상황 | 공식 안내에 따른 행동 |
|---|---|
| 열차 안에서 알았을 때 | 승무원에게 즉시 신고 |
| 역 안 또는 열차에서 내린 직후 | 역무실에 즉시 신고 |
| 역을 떠난 뒤 늦게 알았을 때 | 경찰민원24에서 습득물을 확인하고 철도고객센터 또는 해당 역에 문의 |

**철도고객센터는 1588-7788**이다. 문의할 때 열차번호, 이용구간, 호차와 좌석번호를 준비하면 찾는 데 도움이 된다. 추가로 분실 시각·물건의 종류·색상·특징을 정리해 전달하는 것을 권장한다.

이 문서에서는 전화 연결·실제 분실 접수를 수행하지 않았다. 역별 운영시간과 현재 보관 여부는 방문 전에 해당 역에 확인해야 한다. 모든 유실물센터를 24시간 운영한다고 안내하지 않는다.

## 3. 코레일 모바일 웹에서 찾는 경로

1. [코레일 승차권예매 홈](https://www.korail.com/ticket/main)을 연다. **09번 이미지**가 첫 화면이다.
2. 아래로 내려 **종합이용 가이드 → 유실물**을 누른다. **10번 이미지**를 참고한다.
3. 유실물신고안내에서 철도고객센터와 상황별 신고 방법을 확인한다. **02번 이미지**를 참고한다.
4. 연락처 안내의 **바로가기**를 눌러 역별 연락처 영역으로 이동한다.
5. 역 이름을 입력한 뒤 돋보기 또는 Enter로 검색한다. 조사에서는 **서울**로 검색해 서울역 연락처를 확인했다.

| 확인한 역 | 공식 페이지에 표시된 연락처 | 근거 |
|---|---|---|
| 서울 | **02-755-7108** | `03_역별연락처_서울검색_원본.png`, `서울역연락처_참고기록.json` |

서울역 하나의 번호를 다른 역의 번호로 일반화하지 않는다. 다른 역은 동일한 공식 검색란에서 직접 찾아야 한다. 모바일 표는 가로로 넘겨 볼 수 있으며, 역 이름과 연락처가 같은 행인지 확인한다.

## 4. 습득물 온라인 조회: 현재는 경찰민원24 연결

코레일의 현재 공식 신고 안내는 **경찰민원24**로 연결한다. 검색결과에는 옛 LOST112 주소가 남아 있으므로 글에는 현재 공식 연결을 우선 제공한다.

- [경찰민원24 홈](https://minwon24.police.go.kr/)
- [습득물 검색](https://minwon24.police.go.kr/cvlcpt/cvlcptAply.do?cvlcptId=MW-201)

### 확인한 검색 순서

1. 경찰민원24 홈에서 공지 팝업이 나오면 닫는다.
2. 화면을 내려 **유실물 민원 → 습득물 검색**을 선택한다. **05 → 06번 이미지** 순서다.
3. 검색 필터를 열어 날짜·물품 분류·습득물명 등을 입력한다.
4. 열차 분실물은 **습득장소: 기차**를 선택할 수 있다. 역을 알고 있다면 **보관장소: 서울역**처럼 입력해 범위를 좁힌다. 이 값은 검색 예시이지 모든 분실물의 실제 보관 역을 뜻하지 않는다.
5. **검색하기**를 누르고 결과의 특징·습득일자·보관 장소를 비교한다.
6. 본인 물건으로 보이는 항목은 자세히 보기를 확인하고 보관기관에 수령 방법을 문의한다. 이번에는 개별 상세 개인정보 조회나 전화 문의까지 수행하지 않았다.

조사에서는 `습득장소=기차`, `보관장소=서울역` 조건을 실제 적용했고, 서울역 보관 물건이 결과에 나타남을 확인했다. 검색 건수·물건 목록은 계속 바뀌므로 글에서 고정 수치로 강조하지 않는다. 검색 검증은 `기차서울역_검색검증.json`에 있다.

### 모바일 필터 표시 한계

390px 너비의 모바일 웹에서 일부 검색 필터가 겹치고 표시가 불완전한 현상이 있었다. 이를 실제 서비스의 모든 모바일 환경 문제로 단정하지 않는다. **07번**은 해당 환경의 참고 캡처이며, 독자에게 전체 검색 조건을 설명할 때는 **08번 PC 화면**을 사용한다. PC 화면은 실제 페이지를 1280px 너비에서 다시 렌더링한 것으로, 모바일 앱 화면을 재현한 이미지가 아니다.

처음부터 여러 조건을 과도하게 넣으면 놓칠 수 있다. 찾지 못하면 날짜 범위를 늘리고 보관장소·물품명 일부 조건을 완화하는 방식을 권장한다. 미등록·이관 등도 있을 수 있으므로 검색결과가 없다는 사실만으로 미습득을 확정하지 않는다.

## 5. 조회해도 없으면 분실물 신고 안내

[경찰민원24 분실물 신고 안내](https://minwon24.police.go.kr/cvlcpt/cvlcptGdInfo.do?cvlcptId=MW-001)를 확인한다.

1. 안내 화면의 신청 방법과 서비스 내용을 읽는다.
2. **신고하기**를 누르면 비로그인 상태에서는 로그인이 필요하다는 안내가 나타난다.
3. 이번 수집은 **로그인하러 가기 버튼이 있는 안내창까지**다. 로그인, 인증, 신고서 입력·제출은 하지 않았다.

**습득물 검색**은 누군가 찾아 등록한 물건을 확인하는 기능이고, **분실물 신고**는 잃어버린 사실을 등록하는 기능이다. 두 메뉴를 같은 기능으로 설명하지 않는다. 경찰민원24 안내의 처리기간은 신고 민원 처리에 관한 것이며 물건을 되찾는 데 걸리는 시간을 보장하지 않는다.

## 6. 수령 준비물과 처리 흐름

코레일 공식 안내에 따르면 본인이 역에 방문할 때는 **신분증**이 필요하다. 다른 사람이 대신 받을 때는 **위임장, 분실자 본인의 신분증 사본(사진 가능), 대리인의 신분증**이 필요하다.

[대리수령 위임장 서식 HWP](https://www.korail.com/file/cubedata/COMMON/file/lost_form.hwp)는 공식 페이지에서 연결되는 서식이다. 이번에는 다운로드 버튼이 있는 화면과 링크까지만 기록했다.

공식 처리도에는 **유실물센터에서 1~7일 보관 후 경찰서 인계**, 경찰서 **6개월 보관** 단계가 표시된다. 실제 이관 여부와 현재 보관기관은 반드시 확인한다. 단순히 역에서 무조건 정확히 7일 보관한다고 바꿔 쓰지 않는다. 귀중품·개별 물건의 처리 예외와 법적 소유권 판단까지 이번 조사에서 검토한 것은 아니다.

### FAQ 초안

**내리자마자 물건을 놓고 온 걸 알았다면?** 가까운 역무실에 즉시 알리고 열차번호·호차·좌석번호를 전달한다.

**온라인 조회에 안 나오면 끝인가요?** 미등록·조건 차이·이관 가능성이 있어 날짜·조건을 조정하고 고객센터나 관련 역에 문의한다.

**서울역 연락처는 무엇인가요?** 조사일 공식 역 검색 결과에는 02-755-7108이 표시됐다. 발행·방문 전 현재 공식 번호를 다시 확인한다.

**가족이 대신 받아도 되나요?** 코레일 안내의 위임장·분실자 신분증 사본·대리인 신분증을 준비하고 보관 역에 사전 확인한다.
