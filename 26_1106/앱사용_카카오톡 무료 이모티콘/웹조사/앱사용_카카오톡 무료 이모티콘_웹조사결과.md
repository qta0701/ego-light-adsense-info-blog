## 2. 현재 확인한 방법: 월이무

**공식 페이지:** [매주 월요일은 이모티콘 무료](https://e.kakao.com/weekly_event)

1. 스마트폰 브라우저에서 공식 이벤트 페이지를 연다.
2. 목록에서 원하는 이모티콘 **3종**을 누른다. 선택하면 노란 체크 표시가 생긴다.
3. 하단 받기 버튼을 확인한다. 조사일은 금요일이어서 **다음주에 받기**로 표시됐다.
4. 버튼을 누르면 비로그인 상태에서는 카카오계정 로그인 화면으로 이동한다. 계정이 없는 이용자를 위한 회원가입 링크도 보인다.
5. 로그인 이후의 참여 완료와 실제 지급은 이번 조사에서 검증하지 않았다. 글에는 이 경계까지 확인한 것으로 표시한다.

### 공식 유의사항 요약

| 항목 | 확인한 내용 |
|---|---|
| 월요일 참여 | 바로 지급되는 방식으로 안내 |
| 화~일요일 참여 | 다음 월요일 오전 8~10시 사이 순차 지급 |
| 지급 지연 | 참여자가 많으면 시간이 더 걸릴 수 있음 |
| 사용기간 | 받은 뒤 **3일, 72시간** |
| 참여 횟수 | 하나의 카카오계정으로 매주 1회 |
| 중복 | 이미 보유한 이모티콘은 중복 수령 불가 |
| 앱 상태 | 카카오톡 최신 버전 권장 |
| 변경 가능성 | 일정과 혜택은 변경·종료될 수 있음 |

2026-11-06 참여 예시의 다음 월요일은 **2026-11-09**다. 위 안내에 따르면 오전 8~10시 사이 순차 지급 대상이지만 실제 지급을 보장하는 표현은 쓰지 않는다. 이모티콘 상품명과 목록은 고정 추천 목록이 아닌 촬영 시점의 예시다.

## 3. 검색에 보이는 과거 혜택과 구분할 사항

### 미니 이모티콘 3종

[카카오 2024-03-19 보도자료](https://www.kakaocorp.com/page/detail/10949)는 춘식이의 하루·핑크핑크 어피치·미니 문방구 3종의 무료 제공을 설명한다. 다만 당시 프로모션 URL [mini_open](https://e.kakao.com/mini_open)을 이번에 열었을 때는 **페이지를 찾을 수 없다는 화면**이 나왔다.

따라서 이 과거 URL을 현재 작동하는 무료 다운로드 링크로 소개하면 안 된다. 이 결과만으로 기존 보유자의 이용 가능 여부나 앱 안의 현재 제공 여부까지 판단할 수는 없다. 참고 이미지는 과거 서비스 소개용이며, 현재 신규 다운로드 가능성을 증명하는 자료가 아니다.

### 최대 1년 무료 카드 뽑기

[카카오 2026-10-12 공식 보도자료](https://www.kakaocorp.com/page/detail/12159)의 참여 기간은 **2026-10-12~2026-11-02**다. 조사일인 11월 6일에는 공지된 신규 참여 기간이 지났다. 최대 1년권은 미구독자를 대상으로 한 랜덤 체험 혜택이며 누구에게나 1년 무료가 지급되는 의미가 아니다. 공식 안내의 당첨자 발표일인 11월 9일과 참여 마감일을 혼동하지 않는다.

### 채널 추가 이벤트·이모티콘 플러스

검색결과에는 브랜드 채널 추가형 무료 이벤트도 노출됐다. 이번 조사에서는 특정 브랜드의 현재 모집·잔여 수량을 공식적으로 확인하지 않았으므로 진행 중인 이벤트 목록으로 제공하지 않는다. 후속 글에서는 발행 당일 해당 브랜드 공식 채널 공지를 확인해야 한다.

이모티콘 플러스 체험은 월이무와 별개다. 무료 체험·정기 구독·일반 이모티콘 구매를 같은 혜택으로 설명하지 않는다. 이번에는 구독 시작이나 결제 화면까지 진행하지 않았다.

## 4. 이미지 사용 순서

파일명이 같은 `_원본.png`는 무편집 캡처, `_가이드.png`는 빨간 표식과 한글 안내를 추가한 이미지다. 일반 독자에게는 **01 → 02 → 03 → 04** 순서가 적합하다. 00·05·06은 검색 의도 및 팩트체크 자료다.

미니 이모티콘 보도자료 이미지와 개별 상품 이미지의 원본 WEBP도 보존했다. PNG는 활용 편의를 위해 변환한 파일이다. `참고이미지_출처.json`, `미니이모티콘_이미지출처.json`에 이미지 URL이 있다. 콘텐츠·캐릭터 권리는 제공자에게 있으며, 저장본은 조사·설명용 참고 자료다. 게재 시 출처를 표시하고 상품 자체를 재배포하는 용도로 사용하지 않는다.

모바일 캡처는 **390×844 CSS 픽셀**의 웹 표시를 사용했다. 실제 스마트폰 앱 화면이 아니다. 안내본은 가독성을 위해 2배 확대하고 설명 영역을 별도로 추가했다.
