# Google Sheets 미작성 키워드 조회부터 웹조사까지

.antigravity/rules.md와 guidelines/CHROME_AGENTS_USAGE_GUIDE.md, guidelines/크롬에이전트_활용법.md, guidelines/AGENT_DESKTOP_GUIDE.md를 먼저 읽고, guidelines/웹자료수집.md의 6~8절을 적용해줘. 브라우저는 설치된 ego-browser 스킬과 공개 SDK를 사용해줘.

대상 시트는 [1.애드센스 키워드표](https://docs.google.com/spreadsheets/d/1KAnq9pvZ7VYFJOAQ_25cM8EjaDFUX5Z6x9jfCCtTf7s/edit?usp=sharing)야. 제목이 바뀌어도 이 URL의 문서 ID를 기준으로 확인해줘.

## 작업 대상 추출과 배정

1. 조회용 Space에서 시트를 열고 상단 `🔍 키워드 조회` → `⭐ 1️⃣ 미작성 키워드 전체 시트 조회 (팝업)`를 실행해줘. `전체 시트 미작성 메인 키워드 목록`이 열리면 `📋 전체 기본 복사`를 사용해줘. 섹션을 나눠 가져올 때는 탭의 분할 수를 정하고 `📑 연달아 분리된 섹션 전체 복사`를 사용해줘. 복사 결과가 확인되지 않으면 팝업에 표시된 요약 텍스트를 읽어줘.
2. 목록에서 탭 이름·행 번호·메인 키워드를 추출하고 팝업에 표시된 개수와 대조해줘. Sheets 연결 도구로 검출 행의 I열 키워드와 A·C 상태를 확인해줘. 0개이면 조회 결과만 알려줘.
3. 탭 순서와 행 순서를 유지하고 보통 3개씩 묶어 섹션별 독립 채팅을 같은 프로젝트에서 실행해줘. 한 채팅에는 배정 행만 전달하고 키워드마다 독립 Space를 사용해줘. 섹션당 동시 Space는 해당 섹션의 키워드 수와 실제 자원에 따라 최대 3개로 정해줘. 채팅이나 Space 슬롯이 부족하면 가능한 슬롯으로 여러 묶음을 실행해도 돼. 매 묶음에서 검수와 Space 정리가 끝난 뒤 다음 묶음을 시작해줘. 실제 채팅 생성 여부와 Space 배정을 각각 기록해줘.
4. 새 실행은 `YY_MMDD/_research_runs/`에 배정 파일과 섹션별 manifest를 만들어줘. 재개할 폴더가 지정돼 있으면 기존 `dispatch.json`과 manifest의 행·키워드·Space·결과 파일을 확인하고 남은 단계부터 이어가줘. 재개 범위는 기존 배정이야.

## 조사와 결과 저장

- Google 검색에서 의도를 확인하고 광고를 제외해 실제로 연 공식 출처를 우선해줘. 하나의 키워드에 서로 다른 질문이 있으면 검색어를 2개로 나눠 같은 키워드 Space와 폴더에 기록해줘. 막힌 경우 검색어와 공식 안내 경로를 바꿔 재시도하고, 로그인·가입·설치 화면에서는 진입 지점까지 확인해줘.
- `tools/research_pipeline.py`와 `tools/research_browser.mjs`로 준비·캡처·편집·검증을 돕고, 근거 판단·요약·실제 이미지는 직접 검수해줘. 키워드당 본문 2,000~4,500자 내외(복합 의도 최대 7,500자), 공식 출처 포함 대표 출처 1~2개, 검색어당 검색 화면 1장, 단계 안내 4~8장, 참고 0~3장을 기준으로 해줘. 유의미한 답변과 근거가 확보되면 분량과 장수를 조정하고 이유를 적어줘. 발행용·원본 각각 기본 최대 12장, 복합 의도는 사유 기록 시 최대 14장이야.
- 검색 화면에는 실제로 연 공식 결과를, 단계 이미지에는 설명 대상 요소를 넉넉한 빨간 테두리·화살표·번호로 표시해줘. 화면 크기·배율·PNG 픽셀로 좌표를 검증해줘. 실제 캡처나 표식에 실패하면 원본·다운로드 이미지·본문을 보존하고 공식 이미지나 브라우저 인쇄본 등 활용한 대안과 한계를 명시해줘.
- 새 실행은 오늘 한국 날짜의 `YY_MMDD/{탭}_{키워드}/웹조사/`에 `raw/`, `evidence/`, `publish/`로 저장해줘. 재개는 기존 경로를 사용해줘. `publish/`에 웹조사 Markdown과 발행 이미지를 저장하고, 이미지별 원본·발행 파일명, 배치 순서, 설명, 출처명, 실제 URL, 확인일을 Markdown에 기록해줘. 편집으로 넣는 캡션에는 URL을 넣지 말아줘.

## 완료 처리

- 발행 파일과 이미지를 검수한 행만 I열 키워드와 A·C 공란을 다시 확인해줘. 빈 A열은 실제 완료일의 한국 날짜값(`yyyy-mm-dd` 표시), 빈 C열은 한글 `ㅇ`로 쓰고 같은 셀을 재조회해줘. 미완료 행은 자료와 재개 지점을 보존해줘. 세부 질문을 조정해 조사할 수 있지만 I열 키워드 교체나 신규 행 추가가 필요하면 요청 범위에 포함된 경우에만 적용해줘.
- 팝업에서 확인한 탭과 행, 채팅·Space 배정, 키워드별 결과 경로와 이미지 수, 캡처 대안 또는 미완료 사유, A·C 반영 및 재조회 결과를 알려줘.
