위 [사용자 제공 정보]에 맞춰 벤치마크 블로그 키워드 추출 구글시트에서 카테고리별로 키워드를 선별하여 1.애드센스 키워드표 구글시트의 적합한 탭(또는 지정된 탭) 메인 키워드 열(I열)에 업데이트해줘.

### 1. ego-browser Space 유동적 분할 및 카테고리 헤더열 탐색
- 작업을 시작하기 전에 `ego-browser skill`을 끝 표시(`[ego-browser:skill] end of guide`)까지 읽고 공개 SDK를 사용해줘.
- **유동적 Space 배분**: 사용자가 특정 소수 카테고리를 지정한 경우 2~3개 Space로, "모든 카테고리 키워드 헤더열"처럼 광범위한 범위를 지정한 경우 전체 유효 헤더열을 식별한 뒤 3~5개 Space(권장 3~5개, 최대 5개)를 유동적으로 생성하여 카테고리 블록별로 분산 배분해줘.
- 벤치마크 시트의 지정된 탭(예: `은행_앱_가전`)에는 1행에 `[추출일 | 카테고리 키워드 헤더 | 월간 검색량 합계]` 단위로 여러 카테고리가 나열되어 있고 중간중간 빈 열도 있어. "모든 카테고리" 요청 시 1행에서 키워드가 포함된 유효 헤더열을 모두 자동 추출하여 정렬하고, 동일 탭 내 동명 헤더가 있을 경우 인접 열 순서와 `#fce5cd` 이력을 대조해 특정해줘.
- 각 Space에서 대상 탭을 활성화하고 이름 상자(`#t-name-box`)를 통해 배정된 카테고리 열 및 후보 셀 구간으로 이동하여 확인한 뒤, 작업이 끝나면 모든 Space에서 `await task.finish({ keep: [] })`를 정확히 1회 호출하여 종료해줘.

### 2. `#fce5cd` 배경색 기준점 확인 및 키워드 선별 기준
- 각 카테고리 키워드 열에는 이미 사용한 키워드 셀에 `#fce5cd` 배경색이 지정되어 있어(예: `당근마켓 키워드3` 열에서 마지막으로 사용한 키워드 셀에 `#fce5cd` 배경색 지정).
- 해당 카테고리 열에서 **가장 마지막에 `#fce5cd` 배경색이 지정된 행 이후(`lastColoredRow + 1`행)부터** 사용할 키워드를 N개씩 선별해줘. 만약 해당 카테고리 열에 `#fce5cd` 배경색이 지정된 행이 하나도 없다면 2행(첫 데이터 행)부터 탐색해줘.
- **키워드 선별 기준 (순차적 가이드형 콘텐츠 적합성 판별)**:
  - 단순히 단답형 수치나 사실 하나로 해결되는 키워드가 아니라, **독자가 해당 웹페이지나 모바일 앱을 찾아가서 특정 과정(조회, 신청, 확인, 환불, 취소, 해지, 발권, 택배 예약 등 Step-by-step 가이드)을 밟아야 하는 콘텐츠에 적합한 키워드**로 선별해줘.
  - **과정 안내 적합성 판단 원칙**: 키워드 끝에 `~ 방법`이라는 단어가 직접 붙어있지 않더라도(명사형 키워드라도), 사이트나 앱을 검색해서 찾아가 메뉴를 확인하고 일련의 과정(환불 신청, 시간표 조회 등)을 거쳐야 하는 목적성 키워드는 모두 적극 선별 대상이야.
  - **선별 예시 (O)**:
    - **환불·신청 과정형**: `티머니 환불`, `배민클럽 환불`, `스타벅스 카드 환불`, `스팀 환불 방법`, `애플 환불 요청`, `모바일 티머니 환불` 등 (앱/웹 내 환불 메뉴 이동 및 계좌 신청 절차 안내 가능).
    - **조회·이용 과정형**: `코레일 시간표`, `코레일 예매 확인`, `코레일 내일로 패스`, `코레일 승차권 변경` 등 (레츠코레일/코레일톡 사이트 접속 후 노선 조회 및 시간표 확인·다운로드 과정 안내 가능).
    - **거래·결제·배송형**: `당근마켓 전국검색`, `당근마켓 카드 결제`, `당근마켓 바로구매 택배`, `당근마켓 안심결제`, `번개장터 반값택배`, `번개장터 카드 결제` 등.
    - **설정·해지·탈퇴형**: `카카오톡 광고 차단 방법`, `카카오톡 대화내용 복구`, `넷플릭스 해지방법`, `넷플릭스 로그아웃 티비`, `타오바오 탈퇴 방법`, `네이버회원탈퇴하는방법` 등.
  - **제외 예시 (X)**:
    1) 단답형 수치/정의/기간 종결 키워드 (예: `당근마켓 수수료`처럼 단순히 "수수료는 N%입니다"로 끝나 사이트/앱 접속 절차가 불필요한 키워드, `~ 몇부작`, 단순 규정 `코스트코 환불기간`, `~ 영어로`, `~ mbti`, `코레일 사장` 등).
    2) 단순 작품명·인물명·기업 정보·채용 공고 (예: `~ 채용`, 단순 드라마/영화 제목, `~ 탈퇴멤버`, `환불원정대` 등).
    3) 주체가 결여되어 구체적 접속 절차를 특정할 수 없는 단일어 (예: `환불`).
    4) 타겟 시트(`1.애드센스 키워드표`의 대상 탭 `I열`)에 이미 등록되어 있는 중복 키워드.

### 3. 애드센스 키워드표(I열) 업데이트 및 벤치마크 시트 `#fce5cd` 마킹
- **타겟 시트 탭 매핑 및 I열 업데이트**:
  - 단일 탭 지정 시 해당 탭 `I열`의 마지막 값 이후 빈 행에 업데이트하고, "적합한 카테고리의 탭에 업데이트(없을 경우 이슈, 노하우, 노하우2 배정)" 요청 시 다음 매핑 규칙을 적용해줘:
    - 은행/금융/대출 → `은행_재테크`, 카드 → `카드`, 통신/핸드폰 → `핸드폰`, 가전/AS → `가전`, 앱설치/다운로드 → `다운로드`, 앱사용/플랫폼 → `앱사용`, 보험 → `보험1`, 증권/주식 → `주식정보`, 공공기관/지원금 → `공공기관`/`공공기관2`/`지원금`, 서류/공문서 → `서류양식`, 상품권 → `상품권`, 주차장 → `주차장`, 부동산/청약 → `부동산`, 택배/쇼핑몰 → `일반브랜드`
    - **특정 전용 탭이 없거나 범용적인 생활 노하우/절차 키워드**(예: 계정 탈퇴, 서비스 환불, 단순 시간표 조회 등)는 사용자 지정대로 **`이슈`, `노하우`, `노하우2`** 3개 탭에 균등하게 순환 배정해줘.
  - 각 탭의 `I열(메인 키워드)`에서 마지막 값이 있는 행 이후의 첫 빈 행부터 선별한 키워드들을 순서대로 업데이트해줘. 다른 열(`A~H`, `J~M`)이나 기존 행은 건드리지 마.
- **벤치마크 시트 `#fce5cd` 배경색 지정**: 이번에 선별하여 사용한 벤치마크 시트의 각 키워드 셀에도 기존 서식(글꼴·크기 등)을 유지한 채 배경색만 `#fce5cd` (`red: 0.9882353, green: 0.8980392, blue: 0.8039216`)로 지정하여, 다음 번 작업 시에도 마지막 `#fce5cd` 행 이후부터 이어서 선별할 수 있도록 마킹해줘.
- **검증 및 결과 보고**:
  - 양쪽 시트 업데이트 후 실제 반영된 셀 값과 배경색을 재조회하여 검증해줘.
  - 완료 후 Space별 카테고리 분배 내역, 카테고리별 마지막 `#fce5cd` 기준 행, 선별된 키워드 목록(셀 위치·검색량·선별 사유), 제외된 대표 키워드 및 사유, 그리고 `1.애드센스 키워드표` 탭별 업데이트 결과(탭명·행 번호·키워드)를 표로 깔끔하게 정리해서 알려줘.
