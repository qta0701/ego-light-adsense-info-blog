[실행 범위]
각 계정의 최근 공개 글만 확인해 첫 글의 즉시/예약 시각을 정하고, 같은 계정의 나머지 글은 앞 글의 예상·예정 시각에서 각각 약 2시간씩 뒤로 예약발행해줘. 기존 예약 목록은 확인하지 않아도 돼. 내가 모든 글의 즉시 발행 등 다른 간격을 명시하면 그 지시를 우선해줘.
섹션이 여러 개면 섹션 수만큼 실제 Codex 새 채팅을 만들어 각 섹션을 병렬로 배정해줘. 현재 채팅의 조정자가 전체 배정표·계정별 예정 시각표와 시트 기록을 관리해줘. 각 섹션에서는 키워드마다 배정 계정의 별도 ego-browser TaskSpace를 생성하고 요청한 행들을 처음부터 가능한 한 동시에 진행해줘. 고정된 3개 단위로 나누어 선행 행의 완료를 기다리지 마. 실제 Space·동시 실행 한도가 있으면 가능한 행부터 진행하고 자원이 생기는 즉시 나머지도 시작하며 제약을 알려줘. 이 요청은 여러 Space와 계정별 별도 Space 생성을 명시적으로 허용해.
같은 프로필·같은 네이버 ID에 배정된 서로 다른 키워드도 별도 Space에서 동시에 작성·편집·검수해도 돼. 사용자가 미리 Space를 만들 필요 없이 작업자가 `profiles()` 결과로 해당 프로필을 골라 생성해줘. 사용자가 따로 지정한 기존 Space는 소유권과 기존 초안을 확인하고 사용해줘.

  같은 키워드를 다른 계정에 중복 게시하지 말고 배정표를 저장하여 재시도에도 유지해줘.
  같은 계정이어도 각 행은 작성·검수·최종 제출·결과 확인까지 각각 병렬로 진행해줘. 조정자가 계정별 시각을 미리 배정해 공유하고, 각 행은 그 시각으로 독립 제출해줘. 계정 내 순번은 예정 시각 배정에만 사용하고 다른 행의 실제 발행·제출·결과 확정이나 별도 제출 허가를 기다리지 마. 다른 행의 결과가 불확실해도 이 행은 계속 진행해줘. 단, 결과가 불확실한 동일한 글 자체는 확인 전 다시 제출하지 마.
